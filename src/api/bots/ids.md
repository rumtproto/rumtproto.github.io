# Идентификаторы диалогов Bot API

[@term:peer] Поле `id` у [пиров »](/api/peers/) (пир — любой собеседник или адресат: пользователь, чат, канал или секретный чат) содержит четыре различные последовательности уникальных 64-битных идентификаторов, по которым определяют конкретного пользователя, чат, канал или секретный чат.

Последовательности идентификаторов пользователей, чатов, каналов и секретных чатов **пересекаются**, поэтому имеет смысл преобразовывать идентификаторы пиров в идентификаторы диалогов Bot API так, как описано ниже.

Идентификатор диалога Bot API — это единая уникальная последовательность 64-битных идентификаторов пиров, выведенная из последовательностей идентификаторов пользователей, чатов, каналов и секретных чатов так, что уникальность сохраняется сразу во всех них.  
Идентификаторы диалогов Bot API уже применяются в [bot API](https://core.telegram.org/bots/api) и в лежащей в его основе библиотеке [tdlib](https://github.com/tdlib/td) для обозначения пиров.

Как сказано выше, значащих битов в идентификаторе диалога Bot API может быть больше 32, и в некоторых языках программирования это способно вызвать трудности или молчаливые ошибки при его интерпретации. Однако благодаря диапазонам исходных идентификаторов MTProto (они указаны ниже) значащих битов в нём не более 52, так что такой идентификатор безопасно хранить в 64-битном целом или даже в числе с плавающей точкой двойной точности.

Если точнее, идентификатор диалога Bot API лежит в диапазоне от `-4000000000000` до `1099511627775`.

Преобразовывать идентификаторы пиров в идентификаторы диалогов Bot API стоит даже в том случае, если вы всё же решили [хранить сведения о пирах](/api/peers/) в отдельных базах данных: так идентификаторы станут визуально узнаваемее и для вас, и для ваших пользователей, это гарантирует совместимость с bot API, а ваш клиент сможет определять тип пира по одному лишь идентификатору — благодаря проверкам диапазонов, описанным ниже.

Пример реализации: [tdlib (bot API)](https://github.com/tdlib/td/blob/c19deb1c9fb6d1ecd37db8f4d8148666bbdbb79d/td/telegram/DialogId.cpp), [MadelineProto](https://github.com/danog/tg-dialog-id).

### Идентификаторы пользователей

Идентификаторы [пользователей](/constructor/user/) в MTProto API лежат в диапазоне от `1` до `0xffffffffff` включительно.

Идентификаторы пользователей MTProto совпадают с идентификаторами диалогов пользователей Bot API и наоборот, так что преобразовывать их не нужно — достаточно проверить, что они попадают в указанный выше диапазон.

```
$botApiUserId = $userId;
$userId = $botApiUserId;
```

### Идентификаторы чатов

Идентификаторы [чатов](/constructor/chat/) в MTProto API лежат в диапазоне от `1` до `999999999999` включительно.

Чтобы преобразовать идентификатор чата MTProto в идентификатор диалога чата Bot API, сделайте его отрицательным (и наоборот).

Перед преобразованием всегда проверяйте, что значение попадает в указанный выше диапазон (и наоборот: преобразованный диапазон идентификаторов диалогов чатов Bot API — от `-999999999999` до `-1` включительно).

```
$botApiChatId = -$chatId;
$chatId = -$botApiChatId;
```

### Идентификаторы супергрупп и каналов

Идентификаторы [супергрупп и каналов](/constructor/channel/) в MTProto API используют общую последовательность и лежат в диапазоне от `1` до `997852516352` включительно.

Чтобы преобразовать идентификатор канала MTProto в идентификатор диалога канала Bot API, прибавьте `1000000000000` и сделайте результат отрицательным (и наоборот).

Перед преобразованием всегда проверяйте, что значение попадает в указанный выше диапазон (и наоборот: преобразованный диапазон идентификаторов диалогов каналов Bot API — от `-1997852516352` до `-1000000000001` включительно).

```
$botApiChannelId = -(1000000000000 + $channelId);
$channelId = -$botApiChannelId - 1000000000000;
```

[@term:monoforum] **Примечание**: приведённый выше диапазон **не** распространяется на [monoforum »](/api/monoforum/) — особую разновидность форума для прямых сообщений канала, которая представлена конструкторами [channel](/constructor/channel/) с установленным флагом `monoforum`: диапазон для них смотрите [здесь »](#monoforum-ids).

### Идентификаторы monoforum

[Monoforum »](/api/monoforum/) — особая разновидность форума для прямых сообщений канала; она представлена конструкторами [channel](/constructor/channel/) с установленным флагом `monoforum`.

Идентификаторы monoforum в MTProto лежат в диапазоне от `1002147483649` до `3000000000000`.

Чтобы преобразовать идентификатор monoforum из MTProto в идентификатор monoforum Bot API, прибавьте `1000000000000` и сделайте результат отрицательным (и наоборот): порядок действий тот же, что и для [идентификаторов супергрупп и каналов](#supergroup-channel-ids), меняется только исходный диапазон MTProto.

Перед преобразованием всегда проверяйте, что значение попадает в указанный выше диапазон (и наоборот: преобразованный диапазон идентификаторов диалогов monoforum в Bot API — от `-2002147483649` до `-4000000000000` включительно).

```
$botApiMonoForumId = -(1000000000000 + $monoForumId);
$monoForumId = -$botApiMonoForumId - 1000000000000;
```

### Идентификаторы секретных чатов

[Идентификаторы секретных чатов](/api/end-to-end/) в MTProto API лежат в диапазоне от `-2147483648` до `2147483647` включительно (идентификатор секретного чата следует трактовать как знаковое 32-битное целое с порядком байтов от младшего к старшему, little-endian).

Чтобы преобразовать идентификатор секретного чата MTProto в идентификатор секретного чата Bot API, вычтите `2000000000000`.

[@note] В оригинале этот абзац сформулирован небрежно: там говорится о преобразовании идентификаторов «чатов», хотя весь раздел посвящён секретным чатам. Обратите внимание и на то, что здесь, в отличие от предыдущих разделов, оговорки «и наоборот» нет: обратное преобразование задаёт вторая строка примера кода.

Перед преобразованием всегда проверяйте, что значение попадает в указанный выше диапазон (и наоборот: преобразованный диапазон идентификаторов диалогов секретных чатов Bot API — от `-2002147483648` до `-1997852516353` включительно).

```
$botApiSecretChatId = $secretChatId - 2000000000000;
$secretChatId = $botApiSecretChatId + 2000000000000;
```

Примечание: хотя официальный экземпляр bot API не поддерживает секретные чаты, лежащая в его основе библиотека [tdlib](https://github.com/tdlib/td/) их поддерживает и использует для идентификаторов секретных чатов описанный выше формат.
