# Слои схемы

Оригинальное русскоязычное пояснение к журналу версий схемы. Полный журнал изменений по каждой версии (на английском) — в первоисточнике: [core.telegram.org/api/layers](https://core.telegram.org/api/layers).

Слой (`layer`) — номер версии схемы. Клиент сообщает серверу свой слой через [`invokeWithLayer`](/method/invokeWithLayer/); сервер отвечает структурами не новее этого слоя.

Практические следствия:

- Новые версии приложений поднимают слой и получают новые поля и конструкторы; старые клиенты продолжают работать со своей версией схемы.
- При генерации кода из схемы фиксируйте слой и обновляйте его осознанно: новый слой может добавить обязательные для разбора конструкторы.
- Машиночитаемая схема доступна в [JSON](/schema/json/) для каждого состояния сайта-оригинала; переключатель слоёв на оригинале позволяет смотреть историю.

Журнал содержит сотни записей (по одной на слой) — от базового слоя 1 до текущих версий; переводить построчно его нецелесообразно, это справочник изменений схемы, а не связный текст. За конкретными датами и формулировками обращайтесь к первоисточнику.
