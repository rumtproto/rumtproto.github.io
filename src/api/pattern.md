# Сопоставление с шаблоном

Некоторые методы требуют, чтобы клиент проверил, соответствуют ли определённому шаблону данные, полученные из внешнего источника.

[@term:flash call] Например, при [запросе кода входа](/api/auth/), если выбранный способ подтверждения — [сброшенный звонок](/constructor/auth.sentCodeTypeFlashCall/) (`flash call` — входящий звонок, который сразу сбрасывается, а кодом входа служит номер звонящего), клиент обязан убедиться, что номер телефона (он же код входа) соответствует указанному шаблону.

То же самое относится и к [кодам подтверждения из электронной почты](/constructor/account.sentEmailCode/).

Во всех случаях шаблон — это строка той же длины, что и проверяемая строка, а само сопоставление сводится к простой проверке: все символы исходной строки должны совпадать с символами строки-шаблона. Отдельные символы шаблона могут быть замаскированы звёздочкой `*` — тогда в этой позиции годится любой символ исходной строки.

Шаблоном может быть и одна-единственная звёздочка — в этом случае годными считаются все шаблоны.

[@note] В оригинале здесь сказано «все шаблоны», хотя по смыслу проверку проходит любая исходная строка: шаблон из одной звёздочки принимает что угодно.

Если исходная строка — номер телефона, её сначала обязательно нужно очистить, оставив только следующие символы: `0123456789`.

Пример реализации: [telegram for android](https://github.com/DrKLO/Telegram/blob/68d51749c4fcbaffa584829f23936565df55e08b/TMessagesProj/src/main/java/org/telegram/messenger/AndroidUtilities.java#L3108).
