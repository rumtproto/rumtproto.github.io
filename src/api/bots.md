# Работа с ботами

Работа с ботами средствами MTProto API.

Подробнее о ботах см. [здесь](https://core.telegram.org/bots).

Обратите внимание: для работы с ботами можно также использовать упрощённый [HTTP Bot API](https://core.telegram.org/bots/api), см. [подробнее здесь »](https://core.telegram.org/bots).

### Вход

```
---functions---

auth.importBotAuthorization#67a3ff2c flags:int api_id:int api_hash:string bot_auth_token:string = auth.Authorization;
```

[@term:bot token] Чтобы войти в качестве бота, вместо [обычной процедуры входа по коду](/api/auth/) достаточно передать [bot token](https://core.telegram.org/bots#how-do-i-create-a-bot) — токен бота, выданный [@botfather](https://t.me/botfather).  
При этом [API ID](/api/obtaining_api_id/#obtaining-api-id) указывать всё равно обязательно, как и при входе обычного пользователя.

После успешной авторизации вам будет доступно [большинство методов MTProto API](/methods/) — так же, как обычному пользователю.  
У методов, которые может вызывать бот, стоит пометка **Both users and bots can use this method** или **Only bots can use this method**.

### [Управляемые боты](/api/bots/managed-bots/)

Пользователи могут создавать **управляемые** боты (ими управляет конкретный бот-менеджер) напрямую через MTProto API, не обращаясь к [@BotFather](https://t.me/botfather).

### [Возможности ИИ](/api/bots/ai/)

Боты Telegram предоставляют ряд возможностей для чат-ботов с искусственным интеллектом.

### [Изменение сведений о боте »](/api/bots/info/)

Пользователи могут изменять и локализовать фотографию профиля, имя, текст «о боте» и описание принадлежащих им ботов; то же самое доступно и самим ботам.

### [Команды »](/api/bots/commands/)

[Боты](https://core.telegram.org/bots) предоставляют набор команд, которые пользователи могут вызывать в личной переписке или в чате.

### [Кнопки »](/api/bots/buttons/)

Пользователи могут взаимодействовать с вашим ботом через **кнопки** или даже **инлайн-кнопки** — прямо из инлайн-**сообщений** в **любом** чате.

### [Кнопка меню »](/api/bots/menu/)

Боты могут задать поведение кнопки меню, которая показывается рядом с полем ввода текста.

### [Рекомендуемые права администратора для бота »](/api/rights/#suggested-bot-rights)

При добавлении в группы и каналы бот может предложить набор прав администратора.

### [Инлайн-запросы »](/api/bots/inline/)

[@term:inline query] Пользователи могут взаимодействовать с вашим ботом через **инлайн-запросы** (`inline query` — обращение к боту по его имени пользователя, без добавления бота в чат) — прямо из **поля ввода текста** в **любом** чате.

### [Гостевой режим »](/api/bots/guest-mode/)

К гостевым ботам можно обратиться по имени пользователя из **любого** несекретного чата: свои результаты они публикуют в чат от имени вызвавшего их пользователя.

### [Общение между ботами »](/api/bots/bot-to-bot/)

[@term:Bot-to-Bot Communication Mode] Боты могут обмениваться сообщениями с другими ботами в группах, личных переписках и чатах, если включён режим Bot-to-Bot Communication Mode (режим общения между ботами).

### [Игры »](/api/bots/games/)

Боты могут предлагать пользователям HTML5-игры — в одиночку или на соревнование друг с другом в группах и переписках один на один; как работать с играми через MTProto API.

### [Веб-приложения »](/api/bots/webapps/)

Боты могут предлагать пользователям интерактивные [HTML5-веб-приложения](https://core.telegram.org/bots/webapps), полностью заменяющие **любой сайт**.

#### [Партнёрские программы](/api/bots/referrals/)

[@term:Mini App] Разработчики могут открывать партнёрские программы для своих [mini app](/api/bots/webapps/) (Mini App — веб-приложение, работающее внутри Telegram): это позволяет **авторам контента**, другим **разработчикам mini app** и **любому пользователю Telegram** продвигать приложение и получать комиссию с покупок, совершённых приглашёнными ими людьми.

### [Меню вложений »](/api/bots/attach/)

Боты могут добавлять пункты в меню вложений, предлагая многофункциональные веб-приложения, всегда оказывающиеся под рукой.

### [Бизнес-боты »](/api/bots/connected-business-bots/)

Пользователи могут подключать боты Telegram, которые будут обрабатывать сообщения и отвечать на них **от их имени**. Это позволяет **органично встроить** любые уже используемые инструменты и рабочие процессы либо добавить **ИИ-ассистентов**, которые ведут их переписку.

### [Идентификаторы диалогов в Bot API](/api/bots/ids/)

[@term:peer] Как преобразовать идентификаторы пиров (`peer` — участник переписки: пользователь, обычная группа, супергруппа или канал) из MTProto в идентификаторы диалогов Bot API и обратно.

### [Сторонняя верификация](/api/bots/verification/)

Чтобы ещё больше повысить прозрачность в Telegram, **официальные сторонние сервисы** могут присваивать учётным записям пользователей и чатам **дополнительные значки верификации** — это помогает **предотвращать мошенничество** и **бороться с недостоверной информацией**.
