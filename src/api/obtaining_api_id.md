# Создание своего приложения Telegram

Мы приглашаем всех разработчиков бесплатно использовать наш [API](/api/#telegram-api) и исходный код, чтобы создавать на нашей платформе мессенджеры, подобные Telegram.

> Чтобы обеспечить единообразие и безопасность всей экосистемы Telegram, **все сторонние клиентские приложения** обязаны соблюдать [**Условия использования API**](/api/terms/).

### Получение api\_id

[@term:api_id] Чтобы получить **API id** (`api_id` — числовой идентификатор вашего приложения; вместе с `api_hash` он предъявляется серверу при авторизации) и разрабатывать собственное приложение на базе Telegram API, нужно сделать следующее:

-   Зарегистрироваться в Telegram через официальное приложение.
-   Войти в Telegram core: [https://my.telegram.org](https://my.telegram.org).
-   Перейти в раздел [«API development tools»](https://my.telegram.org/apps) и заполнить форму.
-   Вы получите базовые адреса, а также параметры **api\_id** и **api\_hash**, необходимые для авторизации пользователя.
-   Пока что к каждому номеру можно привязать только один api\_id.

Важные уведомления для разработчиков мы будем отправлять на тот номер телефона, который вы укажете при регистрации приложения, поэтому используйте действующий номер, привязанный к вашему активному аккаунту Telegram.

### Использование api\_id

Прежде чем начинать работу с MTProto Telegram API, учтите: за всеми клиентскими библиотеками API ведётся строгий контроль, чтобы не допустить злоупотреблений.

Если вы используете Telegram API для флуда, спама, накрутки числа подписчиков и просмотров каналов, вас **заблокируют навсегда**.

Из-за многочисленных злоупотреблений Telegram API **все аккаунты**, которые входят через неофициальные клиенты Telegram API, автоматически берутся **под наблюдение** — чтобы не допустить нарушений [Условий использования](/api/terms/).

Если вы не нарушали Условия использования, но ваш аккаунт всё же заблокировали после работы с API, напишите на [recover@telegram.org](mailto:recover@telegram.org): объясните, что вы намерены делать с API, и попросите разблокировать аккаунт.  
Учтите, что письма читает человек, поэтому автоматически сгенерированные письма распознают и заблокируют.

### Использование открытого исходного кода Telegram

Мы приглашаем всех желающих пользоваться нашим открытым исходным кодом. Вместе с кодом мы приводим образец API id. Этот API id ограничен на стороне сервера и не годится для приложений, выпущенных для конечных пользователей: если применять его не только для тестирования, ваши пользователи начнут получать ошибку API\_ID\_PUBLISHED\_FLOOD. Прежде чем публиковать своё приложение, вы обязаны получить **собственный API id**.

> Не забудьте также опубликовать свой код, чтобы соблюсти условия лицензий GNU GPL.
