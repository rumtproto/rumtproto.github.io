# Схема TL (TL-schema)

Схема — это полный набор объявлений на языке [TL](/mtproto/TL/): все типы, конструкторы и методы, которыми клиент обменивается с сервером.

На этом сайте схема представлена справочниками, сгенерированными из оригинала: определения и идентификаторы сохранены без изменений, структурные подписи переведены, короткие описания элементов даны на языке оригинала.

- [Конструкторы](/constructor/) — все конструкторы типов.
- [Методы](/method/) — все методы (RPC-запросы).
- [Типы](/type/) — все типы и связанные с ними конструкторы и методы.
- [Методы по категориям](/methods/) — тематический список методов.

Слои схемы:

- Основная схема API соответствует актуальному слою; выбрать другую версию слоя можно на странице [оригинала](https://core.telegram.org/schema).
- Слой протокола обмена: [схема MTProto](/schema/mtproto/).
- Слой секретных чатов: [схема end-to-end](/schema/end-to-end/).

Машиночитаемые версии (данные, без перевода):

- [Схема API в JSON](/schema/json/)
- [Схема MTProto в JSON](/schema/mtproto-json/)
- [Схема end-to-end в JSON](/schema/end-to-end-json/)

О том, как читать объявления и как значения сериализуются в байты — см. [Язык TL](/mtproto/TL/) и [Сериализация](/mtproto/serialize/).
