# MTProto версии 1.0 (устаревшая)

Версия 1.0 протокола исторически использовалась в ранних клиентах. Сейчас она **устарела и не рекомендуется**: актуальные клиенты используют [MTProto 2.0](/mtproto/).

Основные отличия 1.0 от 2.0:

- Обмен ключом начинался с [`req_pq`](https://core.telegram.org/constructor/req_pq) вместо [`req_pq_multi`](https://core.telegram.org/constructor/req_pq_multi/).
- Иначе выводились ключ и вектор инициализации для шифрования сообщения: использовалась комбинация `SHA1` от `msg_key` и участков `auth_key` (в 2.0 — `SHA256` с другим расположением участков и обязательной привязкой к направлению «клиент→сервер» / «сервер→клиент»).
- В 2.0 добавлена защита от атак на `msg_key`, связанных с подменой направления сообщения.

Оригинальные описания старой версии:

- [Обзор версии 1.0](https://core.telegram.org/mtproto_v1)
- [Подробное описание 1.0](https://core.telegram.org/mtproto/description_v1)
- [Рекомендации по безопасности 1.0](https://core.telegram.org/mtproto/security_guidelines_v1)

Новые реализации следует строить по [текущему описанию](/mtproto/description/) — реализация 1.0 не даст преимуществ, но создаст уязвимости, устранённые в 2.0.
