# E2e.CallPacketLargeMsgId

Конструктор-маркер, идентификатор которого (CRC32) используется при подписи большого идентификатора сообщения, формируемого при шифровании [пакетов группового звонка](/api/end-to-end/group-calls/#packet-encryption).

```
e2e.callPacketLargeMsgId#1ce56c2d = e2e.CallPacketLargeMsgId;
```
