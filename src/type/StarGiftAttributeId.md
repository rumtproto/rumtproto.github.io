# StarGiftAttributeId

*Тип из схемы TL.*

> Represents the _identifier_ of a [collectible gift attribute](https://core.telegram.org/api/gifts#collectible-gifts).

```
starGiftAttributeIdPattern#4a162433 document_id:long = StarGiftAttributeId;

```
