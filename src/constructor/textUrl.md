# textUrl

*Конструктор из схемы TL.*

> Link

## Определение TL

```
textUrl#3c2884c1 text:RichText url:string webpage_id:long = RichText;
```

## Параметры

| Имя | Тип | Описание |
|---|---|---|
| text | [RichText](/type/RichText/) | Text of link |
| url | [string](/type/string/) | Webpage HTTP URL |
| webpage_id | [long](/type/long/) | If a preview was already generated for the page, the page ID |

## Тип

[RichText](/type/RichText/)
