# defaultHistoryTTL

*Конструктор из схемы TL.*

> Contains info about the default value of the Time-To-Live setting, applied to all new chats.

## Определение TL

```
defaultHistoryTTL#43b46b20 period:int = DefaultHistoryTTL;
```

## Параметры

| Имя | Тип | Описание |
|---|---|---|
| period | [int](/type/int/) | Time-To-Live setting applied to all new chats. |

## Тип

[DefaultHistoryTTL](/type/DefaultHistoryTTL/)
