# messages.historyImportParsed

*Конструктор из схемы TL.*

> Contains information about a chat export file [generated by a foreign chat app, click here for more info](https://core.telegram.org/api/import).  
> If neither the `pm` or `group` flags are set, the specified chat export was generated from a chat of unknown type.

## Определение TL

```
messages.historyImportParsed#5e0fb7b9 flags:# pm:flags.0?true group:flags.1?true title:flags.2?string = messages.HistoryImportParsed;
```

## Параметры

| Имя | Тип | Описание |
|---|---|---|
| flags | [#](https://core.telegram.org/type/%23) | Flags, see [TL conditional fields](https://core.telegram.org/mtproto/TL-combinators#conditional-fields) |
| pm | [flags](https://core.telegram.org/mtproto/TL-combinators#conditional-fields).0?[true](/constructor/true/) | The chat export file was generated from a private chat. |
| group | [flags](https://core.telegram.org/mtproto/TL-combinators#conditional-fields).1?[true](/constructor/true/) | The chat export file was generated from a group chat. |
| title | [flags](https://core.telegram.org/mtproto/TL-combinators#conditional-fields).2?[string](/type/string/) | Title of the chat. |
