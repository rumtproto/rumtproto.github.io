# profileTabMusic

Представляет вкладку [музыки](/api/profile/#music) на странице профиля.

```
profileTabMusic#9f27d26e = ProfileTab;
```

### Параметры

Этот конструктор не требует параметров.

### Тип

[ProfileTab](/type/ProfileTab/)
