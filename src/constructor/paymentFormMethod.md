# paymentFormMethod

*Конструктор из схемы TL.*

> Represents an additional payment method

## Определение TL

```
paymentFormMethod#88f8f21b url:string title:string = PaymentFormMethod;
```

## Параметры

| Имя | Тип | Описание |
|---|---|---|
| url | [string](/type/string/) | URL to open in a webview to process the payment |
| title | [string](/type/string/) | Payment method description |
