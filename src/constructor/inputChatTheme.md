# inputChatTheme

*Конструктор из схемы TL.*

> Set an emoji-based chat theme, returned by [account.getChatThemes](/method/account.getChatThemes/).

## Определение TL

```
inputChatTheme#c93de95c emoticon:string = InputChatTheme;
```

| Имя | Тип | Описание |
