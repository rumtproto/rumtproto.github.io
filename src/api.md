# API Telegram

Мы предлагаем разработчикам три вида API. [**Bot API**](#bot-api) позволяет без труда создавать программы, интерфейсом для которых служат сообщения Telegram. [**Telegram API и TDLib**](#tdlib-build-your-own-telegram) позволяют собрать собственный клиент Telegram с любым оформлением и поведением. Оба API можно использовать бесплатно. Наконец, [**Gateway API**](#gateway-api) даёт любому бизнесу, приложению или сайту возможность отправлять коды подтверждения через Telegram вместо обычных SMS.

Кроме того, на свой сайт можно добавить [**виджеты Telegram**](https://core.telegram.org/widgets).

Дизайнеров приглашаем создавать [**анимированные стикеры и эмодзи**](https://core.telegram.org/stickers#animated-stickers-and-emoji) или [**собственные темы оформления**](https://core.telegram.org/themes) для Telegram.

### Bot API

[<img src="https://core.telegram.org/file/811140934/1/tbDSLHSaijc/fdcc7b6d5fb3354adf" title="Botfather. Нажмите, чтобы открыть изображение в высоком разрешении" style="max-width: 200px;float:right">](https://core.telegram.org/file/811140327/1/zlN4goPTupk/9ff2f2f01c4bd1b013)

Этот API позволяет подключать ботов к нашей системе. [**Боты Telegram**](https://core.telegram.org/bots) — это особые аккаунты, для создания которых не нужен отдельный номер телефона. Такие аккаунты служат интерфейсом к коду, работающему где-то на вашем сервере.

Чтобы им пользоваться, не требуется разбираться в устройстве нашего протокола шифрования MTProto: промежуточный сервер возьмёт на себя всё шифрование и общение с Telegram API. С этим сервером вы работаете через простой интерфейс поверх HTTPS, предлагающий упрощённую версию Telegram API.

> [**Подробнее о Bot API »**](https://core.telegram.org/bots)

Разработчикам ботов также доступен [**Payments API**](https://core.telegram.org/bots/payments), позволяющий принимать **платежи** от пользователей Telegram по всему миру.

### TDLib — соберите собственный Telegram

Даже если вам нужна максимальная свобода в настройке, писать приложение с нуля необязательно. Попробуйте [**Telegram Database Library**](https://core.telegram.org/tdlib) (или просто TDLib) — инструмент для сторонних разработчиков, с которым легко создавать быстрые, безопасные и функционально полные приложения Telegram.

TDLib берёт на себя все тонкости **сетевого взаимодействия**, **шифрование** и **локальное хранение данных**, так что вы можете больше времени уделить дизайну, отзывчивому интерфейсу и красивым анимациям.

TDLib поддерживает все возможности Telegram и делает разработку приложений Telegram простой на любой платформе. Библиотеку можно использовать на Android, iOS, Windows, macOS, Linux и практически в любой другой системе. Она распространяется с открытым исходным кодом и совместима практически с **любым языком программирования**.

> [**Подробнее о TDLib »**](https://core.telegram.org/tdlib)

## Gateway API

Telegram Gateway API даёт любому бизнесу, приложению или сайту возможность отправлять коды авторизации через Telegram вместо обычных SMS — это удобный и мощный способ **снизить расходы**, одновременно повысив **безопасность** и **скорость доставки** ваших кодов миллиарду пользователей, ежемесячно активных в Telegram. Пользователи **мгновенно получают** сообщения с кодами в специальном чате внутри Telegram.

> [**Telegram Gateway API можно тестировать совершенно бесплатно. Подробнее »**](https://core.telegram.org/gateway)

#### [Коллекционные предметы](/api/fragment/)

Пользователи Telegram могут упростить другим задачу связаться с ними или найти их публичные группы и каналы с помощью [имён пользователей](https://telegram.org/faq#usernames-and-t-me): кроме того, клиенты могут присваивать аккаунтам, супергруппам и каналам, которыми владеют, несколько **коллекционных имён пользователей** с [Fragment »](https://fragment.com); [Fragment »](https://fragment.com) также позволяет приобретать коллекционные номера телефонов, на которые можно регистрировать аккаунты Telegram.

#### [Telegram Premium](/api/premium/)

Telegram Premium — это необязательная подписка, которая открывает доступ к дополнительным эксклюзивным возможностям на стороне клиента и на стороне API и одновременно помогает поддерживать развитие приложения. Она — часть **устойчивой модели монетизации** Telegram, которую обеспечивают сами пользователи, а не рекламодатели или акционеры. Благодаря этому Telegram может оставаться независимым и ставить интересы пользователей на первое место.

#### [Telegram Business](/api/business/)

Пользователи могут превратить свой аккаунт Telegram в **бизнес-аккаунт** и получить доступ к бизнес-возможностям: часам работы, местоположению, быстрым ответам, автоматическим сообщениям, настраиваемой стартовой странице, поддержке чат-ботов и многому другому.

Большинство возможностей Telegram Business доступно подписчикам [Telegram Premium »](/api/premium/); [подключённые бизнес-боты »](/api/bots/connected-business-bots/) доступны и пользователям без Premium.

#### [Telegram Stars](/api/stars/)

Telegram Stars — это виртуальные предметы, которые позволяют пользователям покупать цифровые товары и услуги у ботов и мини-приложений внутри экосистемы Telegram, отправлять подарки авторам контента на платформе Telegram и не только.

#### [Подписки](/api/subscriptions/)

Боты и каналы могут создавать подписки, периодически списывая с пользователей определённое количество [Telegram Stars](/api/stars/) в обмен на контент и услуги.

#### [Защищённый контент](/api/content-protection/)

Пользователи и боты, которые хотят сохранить свои сообщения приватными, а также владельцы групп и каналов, которые хотят оставить свой контент доступным только участникам, могут запретить пересылку сообщений из своего чата: это также блокирует создание скриншотов, отключает пересылку сообщений (при попытке переслать защищённое сообщение вернётся RPC-ошибка `CHAT_FORWARDS_RESTRICTED`) и ограничивает возможность сохранять медиафайлы из постов.

#### [Подарки](/api/gifts/)

Пользователи могут отправлять **подарки** своим друзьям. Получатели подарков могут показывать их в своём профиле или обменивать на [Telegram Stars »](/api/stars/). Telegram Stars можно использовать по-разному, в том числе для поддержки авторов и покупки услуг в мини-приложениях.

#### [Аукционы коллекционных подарков](/api/auctions/)

Чтобы гарантировать честное распределение [коллекционных подарков](/api/gifts/#collectible-gifts), новые выпуски подарков будут основаны на **аукционах** — пользователи смогут делать ставки в Stars на новые подарки в течение нескольких раундов.

#### [Платные медиафайлы](/api/paid-media/)

Авторы контента могут принимать [Stars](/api/stars/), публикуя в своих каналах **платные фото или видео**. Подписчики смогут просмотреть такие посты, только заплатив автору за их разблокировку.

#### [Платные сообщения](/api/paid-messages/)

Telegram Stars можно использовать для оплаты отправки сообщений пользователям, супергруппам и каналам, которые настроили [платные сообщения »](https://telegram.org/blog/star-messages-gateway-2-0-and-more#stay-in-control-of-your-inbox-with-star-messages) и требуют оплаты за каждое отправленное им сообщение.

### [Доход каналов и ботов от рекламы](/api/revenue/)

В Telegram действует одна из **самых щедрых систем вознаграждения** за всю историю социальных сетей. Владельцы каналов и ботов Telegram теперь могут получать **50 %** дохода от рекламы, которая показывается в их каналах и ботах.

На этой странице описаны методы, которые позволяют вывести доход канала или бота от рекламы, а также посмотреть подробную статистику по доходам.
