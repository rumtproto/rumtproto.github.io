Sending Messages

The input area is fixed at the bottom of the screen. Once the Send button is tapped, the message appears in the message list.

1. Outgoing messages

Three possible conditions exist for outbound messages:

  1. Message is being sent. A clock icon next to the message.
  2. Message has been sent. A single check mark.
  3. Message has been read. A double check mark.


2. Unsent messages

The messages are to be queued for delivery even if no Internet connection is available. If the app is unable to connect to the server within 5 minutes, an exclamation mark icon is shown next to the unsent message.



3. Re-sending unsent messages

Tapping on the unsent message shows a menu with two options – Resend Message and Delete Message.
