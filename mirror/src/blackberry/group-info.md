# Group Chat Info

The group chat info page allows users to edit the title, photo, notification settings and member list of a group. This page is accessed by tapping anywhere on the header in a group chat (including title and photo).

A long tap on a user in the member list allows deleting users from a group. Members can be removed either by the group's creator or by the member who invited them to that group.
