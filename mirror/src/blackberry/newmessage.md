# New Message

[The Action Menu](/blackberry/chats/#3-action-menu) in the [Chats](/blackberry/chats/) or [Contacts](/blackberry/contacts/) section allows users to create chats. There are four options:

#### 1\. New Chat

Open a 1-1 chat with one of the user's contacts. Another way to do the same would be to tap on a contact in the Contacts List.

  

<img src="https://core.telegram.org/file/811140052/1/Qfs4qKho6hM/c3ac16511edba18a55" width="360" height="360">

  

#### 2\. New Group

Shows the group chat creating screen. The user must select members for the new group (up to 199, limit determined by the server), then enter the group's name and (optionally) upload a photo for the group on the next screen.

  

<img src="https://core.telegram.org/file/811140385/1/WoAIhPhtgyk/592678d70133b96b79" width="360" height="360"> <img src="https://core.telegram.org/file/811140350/1/SPnuajYFrwU/8dd0acf8a3416a4d6f" width="360" height="360">

  

  

<img src="https://core.telegram.org/file/811140120/1/R52V_tWXbtQ/dc63b94a9ddc6b92dc" width="360" height="360"> <img src="https://core.telegram.org/file/811140503/1/51MuIhzvRzc/a358b330befac4c2fb" width="360" height="360">

  

#### 3\. New Broadcast

Creates a new broadcast list. There are currently no methods in the API that would allow syncronizing broadcast lists across devices, so all lists are local.
