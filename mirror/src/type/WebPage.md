It can be one of the following:<br><br><br><br>- <code>app</code> - Preview of a <a href="/api/links/#main-mini-app-links">Mini App link »</a>: the <code>photo</code> is the app icon, and clients render a button that launches the <a href="/api/bots/webapps/">Mini App »</a>.<br>- <code>article</code> - Preview of a generic external article or webpage. If <code>embed_url</code>+<code>embed_type</code> are set the GIF is rendered using an embedded player, otherwise the animation is contained in the <code>document</code> field.<br>- <code>photo</code> - Preview of an external photo, contained in the <code>photo</code> field.<br>- <code>profile</code> - Preview of an external author or profile page; clients typically render this with a small thumbnail (forced small media).<br>- <code>telegram_aicomposetone</code> - Preview of an <a href="/api/links/#ai-compose-tone-links">AI compose tone link »</a>, shared when previewing a <a href="/api/ai/#ai-compose-tones">custom AI composer tone »</a>. The <code>attributes</code> field contains a <a href="/constructor/webPageAttributeAiComposeTone/">webPageAttributeAiComposeTone</a> with the <a href="/api/custom-emoji/">custom emoji »</a> representing the tone; clients render a button that applies the shared tone.<br>- <code>telegram_album</code> - Preview of a <a href="/api/links/#message-links">message link »</a> pointing to a group of messages (album), rendered as a grouped media album rather than as a single-media preview. For this type the album media is <strong>not</strong> taken from the top-level <code>photo</code>/<code>document</code> fields: instead, a <a href="#">cached_page</a> (<a href="https://instantview.telegram.org">instant view</a>) must be present, and clients render the items of its first <a href="/constructor/pageBlockCollage/">pageBlockCollage</a> or <a href="/constructor/pageBlockSlideshow/">pageBlockSlideshow</a> block. Each <a href="/constructor/pageBlockPhoto/">pageBlockPhoto</a>/<a href="/constructor/pageBlockVideo/">pageBlockVideo</a> item in that block references a photo or video by ID, resolved against the <code>photos</code> and <code>documents</code> of the <code>cached_page</code>. The instant view itself is not offered as a button (the album media replaces it).<br>- <code>telegram_auction</code> - Preview of an <a href="/api/links/#auction-links">auction link »</a> to a <a href="/api/auctions/">collectible gift auction »</a>. The <code>attributes</code> field contains a <a href="/constructor/webPageAttributeStarGiftAuction/">webPageAttributeStarGiftAuction</a> with the auctioned gift and the auction end date; clients render a button to join the auction, or to view the results once the auction has ended.<br>- <code>telegram_background</code> - Preview of a <a href="/api/links/#wallpaper-links">wallpaper deep link »</a> to a <a href="/api/wallpapers/">chat wallpaper »</a>. The wallpaper settings (background colors, gradient rotation, pattern intensity, blur/motion, etc.) are parsed from the deep link in the <code>url</code>, not from dedicated fields. Image wallpapers carry the wallpaper image in the <code>document</code> field. Pattern wallpapers also use the <code>document</code> field, with <code>application/x-tgwallpattern</code> or <code>image/png</code> as the pattern MIME type; the colors from the <code>url</code> are rendered as the pattern background and tint. Solid-color and gradient wallpapers carry no media and are rendered from the colors encoded in the <code>url</code>. No <code>photo</code> is present. Clients render a button to apply the background.<br>- <code>telegram_bot</code> - Preview of a <a href="/api/links/#bot-links">bot link »</a>, rendered like a profile preview using the bot's avatar in the <code>photo</code> field.<br>- <code>telegram_botapp</code> - Preview of a <a href="/api/links/#direct-mini-app-links">direct Mini App link »</a> to a named bot Mini App: the <code>photo</code> is the app preview, and clients render a button that opens the Mini App.<br>- <code>telegram_call</code> - Preview of a <a href="/api/links/#conference-links">conference link »</a> to a <a href="/api/group-calls/">group call/conference call »</a>; clients render a button to join the call (no <code>photo</code>/<code>document</code> is present).<br>- <code>telegram_channel</code> - Preview of a <a href="/api/links/#public-username-links">public username link »</a> to a channel, using the channel's avatar in the <code>photo</code> field; clients render a "Request to join" button.<br>- <code>telegram_chat</code> - Preview of a <a href="/api/links/#public-username-links">public username link »</a> to a basic group, using the group avatar in the <code>photo</code> field;
