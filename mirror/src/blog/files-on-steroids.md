# Sending Files On Steroids — And More

<img src="https://telegram.org/file/811140836/1/i0Kt-GfBUJs/75aed20c7a21312e98" class="blog_side_image">

Many of you love Telegram for the ability to [send huge files up to 1.5 Gb](/blog/shared-files/).

Today’s [iOS](https://telegram.org/dl/ios) update brings you a radically improved **Send File** menu. We have integrated cloud services like iCloud, DropBox, Google Drive and others, so you can now easily share your existing documents directly from the **Send File** menu.

[<img src="https://telegram.org/file/811140003/1/Whn2DpvGL10/e1385efdb3549f5137" title="Select 'Send File' in the attachment menu" style="padding: 10px 5px; width: 195px">](https://telegram.org/file/811140003/1/Whn2DpvGL10/e1385efdb3549f5137) [<img src="https://telegram.org/file/811140216/1/kXPFfHdygpY/7d82465aba42b774e8" title="Choose file to send" style="padding: 10px 5px; width: 195px">](https://telegram.org/file/811140216/1/kXPFfHdygpY/7d82465aba42b774e8) [<img src="https://telegram.org/file/811140805/2/SWRq_z9oLaA/a931ea6d708123eaaa" title="Redesigned file bubbles in chats" style="padding: 10px 5px; width: 195px">](https://telegram.org/file/811140805/2/SWRq_z9oLaA/a931ea6d708123eaaa)

#### Share multiple files and trim videos

Starting today, you can also share multiple media files at once and see their size and resolution before sending them. As for sharing videos, we added the long-awaited preview and trim functionality to the iOS app.

Another improvement that is specific to iOS for now is the ability to open locations in Google Maps and other non-default map applications, as well as get driving directions.

[<img src="https://telegram.org/file/811140953/1/9WVv2vAL97A/6ca0de993f02fb11ba" title="Select and send multiple files at once" style="padding: 10px 5px; width: 195px">](https://telegram.org/file/811140953/1/9WVv2vAL97A/6ca0de993f02fb11ba) [<img src="https://telegram.org/file/811140677/2/J38ZErehp_Q/e75b8db96a13170029" title="Cut video before sending" style="padding: 10px 5px; width: 195px">](https://telegram.org/file/811140677/2/J38ZErehp_Q/e75b8db96a13170029) [<img src="https://telegram.org/file/811140626/2/Ufp9nOeiW2U/ac0c855f4f6ee50ecf" title="Get driving directions or open location in another map app" style="padding: 10px 5px; width: 195px">](https://telegram.org/file/811140626/2/Ufp9nOeiW2U/ac0c855f4f6ee50ecf)

#### Hashtags and Android features

Hashtags now support non-latin characters on both mobile platforms, and what is more important, recently used hashtags will be instantly suggested when you type the # symbol. This makes them much more usable.

As for improvements to the [Android](https://telegram.org/dl/android) app, this update includes the ability to erase search history for Web images, GIFs and hashtags (simply tap and hold on recent items in search), sounds for incoming and outgoing messages in the currently opened chat and a multitude of design and UI improvements.

In fact, we were lucky to get feedback from the Google design team that provided ideas on how to improve the UI of our Android app. This release has some of these ideas implemented – for example, if you set a custom background for your Telegram chats, it will also be used in the Menu Drawer.

Stay tuned – we are shipping another great update next week.
