# MTProto — документация на русском

Неофициальный русскоязычный справочник по протоколу **MTProto** и схеме данных Telegram,
собираемый как статический сайт на [Eleventy](https://www.11ty.dev/).

Сайт подготовлен как офлайн-дополнение к оригиналу на [core.telegram.org](https://core.telegram.org):

- **Оригинальные русскоязычные статьи** об устройстве протокола и базовых темах уровня API
  (генерация ключа, формат сообщений, безопасность, транспорты, сериализация, сервисные
  сообщения, секретные чаты, обновления, файлы, авторизация и др.) — разделы `mtproto/` и `api/`.
- **Полный справочник схемы** (≈2900 страниц): конструкторы, методы и типы. Определения на
  языке TL сохранены без изменений; подписи и описания снабжены переводом.
- **Глоссарий** терминов с пояснениями на русском.

Термины сохранены в оригинальном написании; каждая страница содержит ссылку на первоисточник.

## Требования

- Node.js ≥ 18 (проверено на 24)
- npm

## Сборка

```bash
cd mtproto_docs
npm install          # устанавливает @11ty/eleventy и turndown
npm run build        # собирает сайт в _site/
```

Готовый сайт лежит в `_site/`. Просмотр:

```bash
npx serve _site      # или любой другой статический сервер
```

### Режим разработки (живая перезагрузка)

```bash
npm run serve        # eleventy --serve → http://localhost:8080/
```

## Структура

```
mtproto_docs/
├── eleventy.config.mjs   # конфигурация Eleventy
├── package.json          # зависимости и скрипты
├── src/                  # исходники сайта
│   ├── _includes/        # шаблон страницы (layout.njk)
│   ├── _data/nav.json    # навигация (генерируется: tools/gennav.mjs)
│   ├── css/style.css     # стили
│   ├── mtproto/...       # статьи о протоколе
│   ├── api/...           # статьи уровня API
│   ├── constructor/...   # справочник конструкторов схемы
│   ├── method/...        # справочник методов схемы
│   ├── type/...          # справочник типов схемы
│   ├── schema/...        # страницы схем (в т.ч. JSON-дампы)
│   ├── glossary.md       # глоссарий
│   └── index.md          # главная
├── tools/                # скрипты конвейера (см. ниже)
└── _site/                # результат сборки
```

## Конвейер генерации (по желанию)

Справочник схемы был сгенерирован из оригинала скриптами в `tools/`:

1. `crawl.mjs` — скачивает страницы с core.telegram.org (сырой HTML).
2. `extract.mjs` — извлекает основной контент: прозу и структуры схемы.
3. `genrefs.mjs` — генерирует страницы конструкторов/методов/типов из извлечённых структур.
4. `genindexes.mjs` — индексы справочника, страница методов по категориям, страницы с
   машиночитаемыми схемами в JSON.
5. `gen_glossary.mjs`, `gennav.mjs` — глоссарий и навигация.

Конвейер полезен при обновлении схемы до нового слоя; для обычной сборки он не нужен.

## Права

Оригинальные тексты и схема принадлежат Telegram (core.telegram.org) и приведены здесь в
объёме, необходимом для реализации совместимых клиентов; определения схемы и идентификаторы
сохранены без изменений. Статьи раздела `mtproto/` и `api/` на этом сайте — оригинальные
русскоязычные объяснения, а не перевод оригинальных статей; за каноническими формулировками
обращайтесь к первоисточнику по ссылкам на каждой странице.
