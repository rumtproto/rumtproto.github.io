Документация MTProto на русском #

Полный русскоязычный перевод документации Telegram: протокола MTProto, Telegram API и справочника схемы TL. Содержимое — снимок оригинала на core.telegram.org (дата снимка указана в подвале); каждая страница ссылается на первоисточник и на английскую версию.¶

Что здесь есть, чего нет в оригинале:¶

  • Перевод абзац в абзац. У каждого абзаца своя метка со ссылкой на тот же абзац английского оригинала: абзац №7 здесь — абзац №7 там.
  • Метки терминов. Непереводимые термины (auth_key, access_hash, pts, file_reference и другие) сохранены в оригинальном написании и поясняются прямо на странице при первом появлении.
  • Пояснения переводчика там, где оригинал труден без дополнительного контекста.
  • Полнотекстовый поиск по всем страницам, включая имена конструкторов, методов и типов — см. страницу поиска; результаты можно ограничить разделом.
  • Якоря на каждом абзаце и заголовке: наведите курсор на абзац, чтобы увидеть ссылку ¶, на заголовок — ссылку #.
  • Боковое меню со всеми статьями раздела и хлебные крошки на каждой странице.

Разделы #

Telegram API #

Прикладной уровень: авторизация, обновления, файлы, секретные чаты, звонки, платежи, боты, каналы, истории и остальные возможности. Начните с указателя API; полный перечень вызовов — в справочнике методов.¶

Протокол MTProto #

Транспортный и криптографический уровень под API: формат сообщений, создание auth_key, сериализация, сервисные сообщения, транспорты и рекомендации по безопасности. Начните с обзора протокола.¶

Схема #

Схема TL: все конструкторы, методы, типы, схема слоя MTProto, схема секретных чатов и машиночитаемые дампы в формате JSON.¶

Прочее #

  • Telegram FAQ — общий пользовательский FAQ с telegram.org (единственная страница за пределами core.telegram.org).
  • FAQ для технически подкованных — вопросы о криптографии и устройстве протокола.

О переводе #

Определения схемы TL, имена конструкторов, методов, полей и коды ошибок сохранены без изменений — их нельзя переводить, не сломав совместимость. Переведены заголовки, текст абзацев, списки и описания в таблицах. Правила, по которым выполняется перевод, собраны в руководстве переводчика.¶
