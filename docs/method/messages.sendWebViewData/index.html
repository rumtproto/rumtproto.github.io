keyboardButtonSimpleWebView #

Кнопка для открытия mini app бота с помощью messages.requestSimpleWebView без передачи сведений о пользователе веб-приложению.¶

Может отправляться или приниматься только в составе клавиатуры ответа; для инлайн-клавиатур используйте keyboardButtonWebView.¶

При нажатии клиенты обязаны открыть Mini App из кнопки клавиатуры с помощью messages.requestSimpleWebView, передав url в поле messages.requestSimpleWebView.url.¶
