TDLib имеет множество опций, влияющих на работу библиотеки. Каждая опция имеет имя и значение. Значение может относиться к одному из следующих типов:¶

Тип значенияЗначение по умолчаниюДиапазон значений
Integer064-битное целое число
BooleanложьИстина или ложь
StringЛюбая строка Unicode

Список опций, поддерживаемых TDLib #

Опции, не упомянутые в этом списке, можно безопасно игнорировать.¶
