Контакты #

При каждом запуске приложения контакты на сервере синхронизируются с адресной книгой телефона. В начале списка отображаются контакты с аккаунтами Telegram, затем остальные контакты устройства.¶

Нажатие на контакт Telegram открывает чат с пользователем. Нажатие на незарегистрированный контакт открывает диалог приглашения — стандартный экран отправки SMS. В поле ввода должен быть стандартный текст со ссылкой, приглашающей пользователя установить приложение.¶

2. Сведения о контакте #

На этот экран можно перейти, нажав:¶

  1. Заголовок с именем и фотографией в личном чате.
  2. Фотографию профиля пользователя рядом с сообщением в группе.
  3. Элемент списка участников на экране сведений о группе.
  4. Имя исходного отправителя в пересланном сообщении.
  5. Элемент списка заблокированных пользователей.
