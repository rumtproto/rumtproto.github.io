Пример генерации авторизационного ключа #

В примерах ниже заголовки транспорта опущены:¶

Например, для сокращённой версии транспорта » клиент отправляет первым байтом 0xef (важно: только перед самым первым пакетом данных), затем длина пакета кодируется одним байтом (0x01-0x7e = длина данных, делённая на 4; либо 0x7f, за которым следуют 3 байта в порядке little endian — от младшего байта к старшему, — делённые на 4), а следом идут сами данные. Ответы сервера в этом случае имеют такую же структуру (правда, сервер не отправляет 0xef первым байтом). Подробная документация по созданию авторизационных ключей доступна здесь ».¶
