Приложения Telegram #

Приложения Telegram имеют открытый исходный код и поддерживают воспроизводимые сборки. Каждый может самостоятельно проверить, что приложения Telegram, загружаемые из App Store или Google Play, собраны из точно того же кода, который мы публикуем.¶

Мобильные приложения #

  • Telegram for Android
  • Telegram for iPhone and iPad

Приложения для компьютера #

  • Telegram for Windows/Mac/Linux
  • Telegram for macOS

Веб-приложения #

  • Telegram WebK
  • Telegram WebA

Библиотека базы данных Telegram (TDLib) #

  • TDLib — кроссплатформенный клиент, предназначенный для упрощения создания пользовательских приложений на платформе Telegram.
  • Telegram X для Android — стильный экспериментальный клиент Telegram на базе TDLib.

Неофициальные приложения #

  • Unigram — клиент, оптимизированный для Windows (на базе TDLib)
  • Telegram CLI for Linux
  • MadelineProto
