Импорт стикеров в Telegram #

Самый простой способ создавать стикеры в Telegram — загружать их через бота @stickers. Этот бот поможет загружать новые стикеры, создавать наборы стикеров и получать статистику использования стикеров и наборов.¶

Telegram также предлагает платформу для разработчиков приложений, которые помогают пользователям создавать собственные стикеры. Например, приложений, позволяющих загружать свои фотографии и превращать их в стикеры.¶

Для кого это? #

ИСПОЛЬЗУЙТЕ ЭТО:¶

  • Чтобы помогать людям создавать собственные уникальные пользовательские стикеры.
  • Чтобы помогать людям переносить уникальные пользовательские стикеры, созданные ими на другой платформе.

НЕ используйте это:¶

  • Чтобы делиться загруженными стикерами с другими пользователями Telegram.
  • Вместо этого загрузите стикеры с помощью бота @stickers и поделитесь ссылкой на свой набор (например, https://t.me/addstickers/UtyaDuck).

Короче говоря, если набор стикеров уже доступен в Telegram, импортировать его не нужно!¶

Приложения для импорта стикеров #

Начиная с версии 7.8 приложения Telegram поддерживают простой API для импорта стикеров.¶

Think outside the fox.

ПРЕДУПРЕЖДЕНИЕ: При каждом импорте стикеров пользователем в Telegram создаётся новый набор стикеров. Не используйте импорт, чтобы делиться созданными стикерами с другими пользователями. Если хотите поделиться стикерами, загрузите их через @stickers и поделитесь ссылкой на набор. Например, вот ссылка для установки стикеров с утками.¶

SDK для импорта #

Мы создали библиотеки и примеры приложений для iOS и Android, с помощью которых можно реализовать импорт стикеров в Telegram из своего приложения.¶

Форматы стикеров #

Приложения Telegram поддерживают два типа стикеров. Независимо от типа, с каждым стикером должен быть связан хотя бы один эмодзи, выражающий соответствующую ему эмоцию.¶

Анимированные стикеры #

Должны быть в формате TGS и создаваться с помощью плагина Bodymovin-TG для Adobe After Effects.¶

Примечание: Анимированный .WEBP сейчас НЕ поддерживается; для статических стикеров поддерживается только статический .WEBP. Анимированные стикеры должны быть в формате .TGS. Также можно импортировать видеостикеры в формате .WEBM.¶

Макс. размер: 64 КБ
Размеры: 512x512 пикс.
FPS: 30–60 FPS
Макс. длительность: 3 секунды¶

Полные технические сведения об анимированных стикерах Telegram приведены на этой странице.¶

Видеостикеры #

Должны быть в формате WEBM с кодированием VP9 и альфа-каналом (прозрачность — временное требование).¶

Макс. размер: 256 КБ
Макс. размеры: 512x512 пикс., хотя бы одна сторона изображения должна быть 512 пикс.
FPS: 30
Макс. длительность: 3 секунды¶

Статические стикеры #

Должны быть в формате PNG или WEBP с прозрачным слоем. Все статические стикеры должны иметь белую обводку и тень, точно как в этом примере: StickerExample.psd¶

Макс. размер: 512 КБ
Макс. размеры: 512x512 пикс., хотя бы одна сторона изображения должна быть 512 пикс.¶
