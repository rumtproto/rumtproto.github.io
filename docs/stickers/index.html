Стикеры Telegram #

Все пользователи могут создавать, отправлять и делиться собственными работами, используя открытую платформу Telegram для стикеров и эмодзи. Встроенный редактор стикеров позволяет обычным пользователям легко создавать стикеры в приложении Telegram из собственных фотографий, чтобы делиться ими в чатах.¶

Художники и создатели контента могут делать векторные анимации, видеофайлы и статические изображения в предпочитаемых приложениях, а затем загружать их через мини-приложение @Stickers, чтобы делиться своими работами с более чем 1 миллиардом пользователей.¶

Создание стикеров в Telegram #

Любой пользователь Telegram может создавать пользовательские стикеры в любом чате Telegram, превращая фотографии в творческие работы, которые можно сохранять и использовать где угодно.¶

Создание стикеров в приложении #

С помощью встроенного редактора стикеров можно быстро превратить любую фотографию на устройстве в пользовательский стикер, добавив текст, рисунки, эмодзи и многое другое. Это позволяет каждому легко создавать собственные стикеры без специального ПО прямо в чате.¶

Creating Stickers in Telegram

Редактор стикеров также позволяет создавать наборы пользовательских стикеров, которыми можно делиться с друзьями и близкими.¶

Adding a Sticker to a Set

Чтобы открыть редактор стикеров, откройте панель стикеров из поля ввода в любом чате и нажмите кнопку (+).¶

Мини-приложение @Stickers #

@Stickers позволяет каждому создавать наборы и управлять ими — как со стикерами, так и с эмодзи, просматривать подробную статистику использования и многое другое в едином интуитивно понятном интерфейсе.¶

Stickers Mini App

Функции бота @Stickers также доступны через текстовые команды.¶

Создание стикеров с помощью ПО #

Художники и создатели контента могут делать стикеры в нескольких форматах в предпочитаемых редакторах, а затем загружать готовые файлы анимации, видео или изображений как стикеры и эмодзи.¶

Анимированные стикеры и эмодзи #

Стикеры и эмодзи Telegram могут двигаться с плавной анимацией 60 FPS, оживляя персонажей в высоком разрешении.¶

Для анимаций необходим уникальный формат .TGS Telegram; нажмите здесь, чтобы узнать о видеостикерах и эмодзи, созданных в формате .WEBM.¶

Создание анимаций¶

Для создания векторных анимированных стикеров и эмодзи потребуется следующее:¶

  1. Любой редактор векторной графики, позволяющий экспортировать векторные объекты в Adobe After Effects для превращения их в анимации.
  2. Программа Adobe After Effects.
  3. Плагин Bodymovin-TG — ответвление Bodymovin для Adobe After Effects, которое можно использовать для экспорта анимаций в формат .TGS Telegram.

Формат .TGS на основе Lottie позволяет создавать невероятно детализированные анимации размером менее 30 КБ — в шесть раз меньше средней фотографии.¶

Требования к анимациям¶

  • Размер холста должен составлять 512х512 пикселей.
  • Объекты не должны выходить за пределы холста.
  • Длительность анимации не должна превышать 3 секунд.
  • Все анимации должны быть зациклены.
  • Размер итогового файла после рендеринга в Bodymovin не должен превышать 64 КБ.
  • Все анимации должны воспроизводиться с частотой 60 кадров в секунду.
  • При анимации своих работ нельзя использовать следующие возможности Adobe After Effects: автоматические ключи Безье, выражения, маски, эффекты слоя, изображения, сплошные заливки, текст, трёхмерные слои, объединение контуров, звёздные фигуры, градиентные обводки, повторители, растяжение времени, переназначение времени, автоматически ориентируемые слои.

Видеостикеры и эмодзи #

Стикеры и эмодзи также можно создавать в .WEBM — формате с открытым исходным кодом, совместимом со многими графическими редакторами и позволяющем делать детализированные изображения. Требуется Telegram 8.5 или новее.¶

Создание видео¶

Чтобы создавать стикеры и эмодзи из видеофайлов, нужен только редактор, позволяющий экспортировать проект как видеофайл .WEBM.¶

Требования к видео¶

Подробности смотрите в руководстве по кодированию .WEBM с VP9¶

  • Для стикеров одна сторона должна быть ровно 512 пикселей, а другая — 512 пикселей или меньше.
  • Для эмодзи размер видео должен быть ровно 100x100 пикселей
  • Длительность видео не должна превышать 3 секунд.
  • Частота кадров может составлять до 30 FPS.
  • Для наилучшего пользовательского опыта видео следует зациклить.
  • Размер видео не должен превышать 256 КБ.
  • Видео должно быть в формате .WEBM, закодированном кодеком VP9.
  • У видео не должно быть аудиодорожки.

Статические стикеры и эмодзи #

Превратите любимые рисунки и мемы в наборы изображений, которыми легко делиться и пользоваться на любом устройстве.¶

Создание изображений
Чтобы создавать статические стикеры и эмодзи для Telegram, нужен только редактор изображений, позволяющий экспортировать в формате .PNG или .WEBP.¶

Требования к изображениям¶

  • Для стикеров одна сторона должна быть ровно 512 пикселей, а другая — 512 пикселей или меньше.
  • Для эмодзи размер изображений должен быть ровно 100x100 пикселей.
  • Файл изображения должен быть в формате .PNG или .WEBP.

Совет: прозрачный фон, белая обводка и эффект чёрной тени помогут вашему стикеру выделиться.¶

Пользовательские эмодзи #

Начиная с версии 8.9, выпущенной в августе 2022 года, приложения Telegram поддерживают пользовательские эмодзи.
Эмодзи используют ту же технологию, что и стикеры, поэтому свои работы очень легко преобразовать в оба формата. Подробнее о различных требованиях к размерам смотрите в разделах видео и изображений.¶

Создавать новые пользовательские эмодзи может каждый, однако добавление и использование пользовательских наборов сейчас является эксклюзивной функцией пользователей Telegram Premium.¶

Адаптивные эмодзи #

Если планируется создать набор простых значков со сплошными цветами, которые меняют цвет в зависимости от места использования, при создании набора эмодзи можно отправить команду /adaptive.¶

При использовании в качестве эмодзи-статусов и значков тем такие эмодзи будут соответствовать акцентному цвету темы пользователя. В сообщении они будут соответствовать цвету текста этого сообщения.¶

Импорт стикеров из других приложений #

Разработчики могут создавать приложения для автоматизации импорта стикеров с помощью API Telegram. С этими инструментами пользователи могут мгновенно переносить любимые стикеры в Telegram.¶

Для пользователей #

Пользователи могут найти приложения, позволяющие импортировать стикеры или быстро создавать собственные. Они также могут легко публиковать пользовательские стикеры через бота @Stickers, используя файлы .PNG, .WEBP или .WEBM со стикерами из других приложений.¶

Для разработчиков #

Начиная с версии 7.8, приложения Telegram поддерживают простой API для импорта стикеров. Разработчики могут использовать его, чтобы создавать приложения или добавлять инструменты в приложения, позволяющие пользователям мгновенно переносить стикеры в Telegram или создавать пользовательские стикеры из фотографий и видео.¶
