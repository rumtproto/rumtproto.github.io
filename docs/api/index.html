API Telegram #

Мы предлагаем разработчикам три вида API. Bot API позволяет без труда создавать программы, интерфейсом для которых служат сообщения Telegram. Telegram API и TDLib позволяют собрать собственный клиент Telegram с любым оформлением и поведением. Оба API можно использовать бесплатно. Наконец, Gateway API даёт любому бизнесу, приложению или сайту возможность отправлять коды подтверждения через Telegram вместо обычных SMS.¶

Кроме того, на свой сайт можно добавить виджеты Telegram.¶

Дизайнеров приглашаем создавать анимированные стикеры и эмодзи или собственные темы оформления для Telegram.¶

Bot API #

Botfather. Нажмите, чтобы открыть изображение в высоком разрешении¶

Этот API позволяет подключать ботов к нашей системе. Боты Telegram — это особые аккаунты, для создания которых не нужен отдельный номер телефона. Такие аккаунты служат интерфейсом к коду, работающему где-то на вашем сервере.¶

Чтобы им пользоваться, не требуется разбираться в устройстве нашего протокола шифрования MTProto: промежуточный сервер возьмёт на себя всё шифрование и общение с Telegram API. С этим сервером вы работаете через простой интерфейс поверх HTTPS, предлагающий упрощённую версию Telegram API.¶

Подробнее о Bot API »¶

Разработчикам ботов также доступен Payments API, позволяющий принимать платежи от пользователей Telegram по всему миру.¶

TDLib — соберите собственный Telegram #

Даже если вам нужна максимальная свобода в настройке, писать приложение с нуля необязательно. Попробуйте Telegram Database Library (или просто TDLib) — инструмент для сторонних разработчиков, с которым легко создавать быстрые, безопасные и функционально полные приложения Telegram.¶

TDLib берёт на себя все тонкости сетевого взаимодействия, шифрование и локальное хранение данных, так что вы можете больше времени уделить дизайну, отзывчивому интерфейсу и красивым анимациям.¶

TDLib поддерживает все возможности Telegram и делает разработку приложений Telegram простой на любой платформе. Библиотеку можно использовать на Android, iOS, Windows, macOS, Linux и практически в любой другой системе. Она распространяется с открытым исходным кодом и совместима практически с любым языком программирования.¶

Подробнее о TDLib »¶

Gateway API #

Telegram Gateway API даёт любому бизнесу, приложению или сайту возможность отправлять коды авторизации через Telegram вместо обычных SMS — это удобный и мощный способ снизить расходы, одновременно повысив безопасность и скорость доставки ваших кодов миллиарду пользователей, ежемесячно активных в Telegram. Пользователи мгновенно получают сообщения с кодами в специальном чате внутри Telegram.¶

Telegram Gateway API можно тестировать совершенно бесплатно. Подробнее »¶

Telegram API #

Этот API позволяет создавать собственные клиенты Telegram с любым оформлением и поведением. Он на 100% открыт для всех разработчиков, желающих делать приложения на нашей платформе. Изучайте открытый исходный код существующих приложений Telegram — это хорошие примеры того, как всё устроено. Не забудьте зарегистрировать своё приложение в нашей системе.¶

Возможности ИИ #

Telegram предлагает множество возможностей на основе ИИ, работающих поверх Cocoon — децентрализованной сети, спроектированной для максимальной приватности.¶

Идентификаторы диалогов Bot API #

Идентификатор диалога Bot API — это единая уникальная 64-битная последовательность идентификаторов пиров (peer — любой адресуемый объект: пользователь, чат, канал или секретный чат), выведенная из последовательностей идентификаторов пользователей, чатов, каналов и секретных чатов так, чтобы оставаться уникальной сразу во всех них.¶

На этой странице описано, как преобразовывать идентификаторы пиров MTProto в идентификаторы диалогов Bot API и обратно.¶

Управляемые боты #

Пользователи могут создавать управляемые боты (которыми распоряжается определённый бот-менеджер) напрямую через MTProto API, без обращения к @BotFather.¶

Команды #

Боты предлагают набор команд, которыми пользователи могут воспользоваться в личной переписке или в чате.¶

Кнопки #

Пользователи могут взаимодействовать с вашим ботом с помощью кнопок и даже инлайн-кнопок — прямо из инлайн-сообщений в любом чате.¶

Кнопка меню #

Боты могут выбирать поведение кнопки меню, отображаемой рядом с полем ввода текста.¶

Инлайн-запросы #

Пользователи могут взаимодействовать с вашим ботом с помощью инлайн-запросов (inline query — обращение к боту прямо из поля ввода, без добавления его в чат) — прямо из поля ввода текста в любом чате.¶

Игры #

Боты могут предлагать пользователям HTML5-игры, чтобы играть в одиночку или соревноваться друг с другом в группах и в личных чатах; как работать с играми через MTProto API.¶

Mini apps #

Боты могут предлагать пользователям интерактивные HTML5 mini apps (Mini App — веб-приложение, работающее внутри Telegram), полностью заменяющие любой сайт.¶

Партнёрские программы #

Разработчики могут открывать партнёрские программы для своих mini app — позволяя авторам контента, другим разработчикам mini app и любому пользователю Telegram продвигать их и получать комиссию с покупок, совершённых приведёнными ими людьми.¶

Меню вложений #

Боты могут устанавливать записи в меню вложений, предлагая удобно доступные и разносторонние mini app.¶

Изменение информации о боте #

Пользователи могут изменять и локализовать фотографию профиля, имя, текст «о себе» и описание принадлежащих им ботов; то же самое могут делать и сами боты.¶

ИИ-боты #

Боты Telegram предлагают ряд возможностей для ИИ-чатботов.¶

Гостевой режим #

К гостевым ботам можно обращаться по имени пользователя из любого несекретного личного чата, группы и супергруппы, и они публикуют свои результаты прямо в чат, даже если не состоят в нём.¶

Общение между ботами » #

Боты могут получать и отправлять сообщения другим ботам в группах, личных чатах и чатах, если включён режим общения между ботами.¶

Истории #

Пользователи и каналы Telegram могут легко публиковать и просматривать истории через API.¶

Похожие каналы и боты #

API предлагает метод для получения списка публичных каналов и ботов схожей тематики, отобранных на основе сходства их аудиторий подписчиков.¶

Акцентные цвета #

Пользователи и каналы Telegram могут менять акцентный цвет и фоновый узор своей страницы профиля и своих сообщений!¶

Настройки приватности #

Telegram позволяет пользователям задавать детальные настройки приватности, выбирая, кто может и кто не может взаимодействовать с ними определёнными способами.¶

Поиск и фильтры #

Telegram позволяет применять детальные фильтры сообщений при поиске сообщений в чатах.
Это позволяет серверу отбирать сообщения по текстовому запросу и даже по их типу; графические клиенты часто используют эту возможность для реализации таких функций, как галерея чата, фотографии профиля чата и многое другое.¶

Опросы #

Telegram позволяет отправлять опросы и викторины, в которых могут проголосовать тысячи, если не миллионы пользователей в чатах и каналах.¶

Списки задач #

Пользователи Premium теперь могут создавать совместные списки задач в любом чате, чтобы отслеживать задачи и координировать работу команд — или вести списки покупок и дел.¶

Реакции #

Telegram позволяет пользователям реагировать на любое сообщение определёнными эмодзи, запуская симпатичные Lottie-анимации.¶

Анимированные эффекты для сообщений #

Telegram позволяет добавлять зрелищные анимированные эффекты к отправляемым вами сообщениям.¶

Категории эмодзи #

Интерфейсы выбора стикеров, пользовательских эмодзи и GIF должны предлагать список категорий для быстрой фильтрации результатов по эмодзи (или списку эмодзи), либо по какому-то другому критерию.¶

Эмодзи-статус #

Telegram позволяет пользователям устанавливать смайлик или пользовательский эмодзи в качестве статуса, который показывается рядом с их именем в чатах и профилях.¶

Пригласительные ссылки и заявки на вступление #

У каналов, обычных групп и супергрупп может быть публичное имя пользователя или приватная пригласительная ссылка: приватные пригласительные ссылки можно дополнительно усилить заявками на вступление от каждого пользователя.¶

Как работать с правами администраторов, детальными блокировками и глобальными правами в каналах, группах и супергруппах.¶

Группы обсуждения #

Группы можно связать с каналом в качестве группы обсуждения, что позволяет пользователям обсуждать публикации.¶

Комментарии в каналах и ветки сообщений #

Telegram позволяет комментировать публикацию в канале или обычное сообщение в группе благодаря веткам сообщений.¶

Журнал администратора #

И супергруппы, и каналы предлагают так называемый журнал администратора — список недавних значимых действий в супергруппе и канале, таких как изменение настроек или информации группы/канала от имени администратора, исключение и блокировка пользователей и многое другое.¶

Telegram Premium #

Telegram Premium — это необязательная подписка, которая открывает доступ к дополнительным эксклюзивным возможностям на стороне клиента и на стороне API и одновременно помогает поддерживать развитие приложения. Она — часть устойчивой модели монетизации Telegram, которую обеспечивают сами пользователи, а не рекламодатели или акционеры. Благодаря этому Telegram может оставаться независимым и ставить интересы пользователей на первое место.¶

Telegram Business #

Пользователи могут превратить свой аккаунт Telegram в бизнес-аккаунт и получить доступ к бизнес-возможностям: часам работы, местоположению, быстрым ответам, автоматическим сообщениям, настраиваемой стартовой странице, поддержке чат-ботов и многому другому.¶

Большинство возможностей Telegram Business доступно подписчикам Telegram Premium »; подключённые бизнес-боты » доступны и пользователям без Premium.¶

Telegram Stars #

Telegram Stars — это виртуальные предметы, которые позволяют пользователям покупать цифровые товары и услуги у ботов и мини-приложений внутри экосистемы Telegram, отправлять подарки авторам контента на платформе Telegram и не только.¶

Подписки #

Боты и каналы могут создавать подписки, периодически списывая с пользователей определённое количество Telegram Stars в обмен на контент и услуги.¶

Защищённый контент #

Пользователи и боты, которые хотят сохранить свои сообщения приватными, а также владельцы групп и каналов, которые хотят оставить свой контент доступным только участникам, могут запретить пересылку сообщений из своего чата: это также блокирует создание скриншотов, отключает пересылку сообщений (при попытке переслать защищённое сообщение вернётся RPC-ошибка CHAT_FORWARDS_RESTRICTED) и ограничивает возможность сохранять медиафайлы из постов.¶

Подарки #

Пользователи могут отправлять подарки своим друзьям. Получатели подарков могут показывать их в своём профиле или обменивать на Telegram Stars ». Telegram Stars можно использовать по-разному, в том числе для поддержки авторов и покупки услуг в мини-приложениях.¶

Аукционы коллекционных подарков #

Чтобы гарантировать честное распределение коллекционных подарков, новые выпуски подарков будут основаны на аукционах — пользователи смогут делать ставки в Stars на новые подарки в течение нескольких раундов.¶

Платные медиафайлы #

Авторы контента могут принимать Stars, публикуя в своих каналах платные фото или видео. Подписчики смогут просмотреть такие посты, только заплатив автору за их разблокировку.¶

Платные сообщения #

Telegram Stars можно использовать для оплаты отправки сообщений пользователям, супергруппам и каналам, которые настроили платные сообщения » и требуют оплаты за каждое отправленное им сообщение.¶
