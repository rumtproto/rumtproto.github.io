Участники групповых чатов (как обычных групп, так и супергрупп) теперь могут добавить рядом со своим именем метку — чтобы показать свою должность на работе, специальность, по которой они учатся, и тому подобное.¶

Чтобы изменить метку, вызовите messages.editChatParticipantRank со следующими параметрами:¶

  • peer: группа
  • user_id: пользователь, чью метку требуется изменить. Администратор с правом администратора » manage_ranks может изменить метку любого участника.
    Все остальные могут изменить только собственную метку, и то лишь при выполнении хотя бы одного из условий:
    • права чата по умолчанию разрешают edit_rank И/ИЛИ
    • ограничения пользователя разрешают edit_rank
  • rank: новая метка (не более 16 символов, без эмодзи)

Для супергрупп метка будет доступна в следующих местах:¶

  • Во флаге message.from_rank всех сообщений, отправленных участниками группы
  • Во флаге ChannelParticipant.rank, который можно получить методами channels.getParticipant/channels.getParticipants

Для обычных групп метка будет доступна в следующих местах:¶

  • Во флаге ChatParticipant.rank, доступном в chatFull.participants, — его обязательно всегда кешировать локально »
  • Изменения меток пользователей будут приходить как обновления updateChatParticipantRank (только для обычных групп; супергруппам это не нужно, поскольку message.from_rank всегда содержит актуальную метку)
  • Для обычных групп message.from_rank не заполняется: вместо этого клиентам следует брать метки из ChatParticipant.rank для всех участников обычной группы

У администраторов метка тоже есть, и она всегда окрашена в цвет » пира — так их отличают от остальных участников.¶

Только для администраторов и создателя: если флаг rank не задан, клиентам следует по умолчанию показывать «Владелец» для channelParticipantCreator и «Администратор» для channelParticipantAdmin.¶

Менять метки администраторов супергруппы можно и методом messages.editChatParticipantRank, и методом channels.editAdmin.¶
