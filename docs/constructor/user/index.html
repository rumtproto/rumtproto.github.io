user #

Содержит сведения об определённом пользователе.¶

Если не указано иное, при обновлении локальной базы пиров все поля вновь полученного конструктора имеют приоритет над старым конструктором, сохранённым локально (в том числе поля, не заданные в новом конструкторе, удаляются).¶

См. здесь » реализацию логики, которую следует применять при обновлении локальной базы пиров-пользователей.¶

- Устанавливается в true, если установлен min И
-- Флаг phone не установлен ИЛИ
-- Флаг phone установлен, а связанная строка с номером телефона непуста
- В остальных случаях устанавливается в false.

Затем access_hash и min_access_hash применяются к локальной базе, если:
- min_access_hash равен false ИЛИ
- min_access_hash равен true И
-- Локально закешированного объекта для этого пользователя нет ИЛИ
-- В локальном кеше нет access_hash ИЛИ
-- У закешированного объекта min_access_hash тоже равен true

Если у итогового объединённого объекта, сохранённого в базе, поле min_access_hash равно true, то соответствующий access_hash пригоден только для использования в inputPeerPhotoFileLocation » — для непосредственной загрузки фотографий профиля пользователей; во всех остальных случаях потребуется сформировать конструктор inputPeer*FromMessage, как описано здесь ».
Боты при некоторых условиях также могут использовать min-хеши доступа, передавая 0 вместо min-хеша доступа.

Связанные страницы #

База данных пиров #

Многие конструкторы API необходимо сохранять в локальной базе данных при получении; обновлять их следует только реактивно (пассивно) — когда они приходят через обновления или иным способом, указанным в документации, — чтобы не перегружать сервер постоянными запросами изменений одних и тех же неизменившихся данных.¶

userFull #

Расширенные сведения о пользователе¶

При обновлении локальной базы пиров » все поля вновь полученного конструктора имеют приоритет над старым конструктором, сохранённым локально (в том числе удаляются поля, не заданные в новом конструкторе).¶

Конструкторы min #

В некоторых случаях в конструкторах пользователя и канала присутствует сокращённый набор полей (хотя id есть всегда) и установлен флаг min.¶

Пункты меню вложений и бокового меню для ботов #

Боты могут добавлять пункты в меню вложений и в боковое меню, предлагая легкодоступные многофункциональные веб-приложения.¶

help.getConfig #

Возвращает текущую конфигурацию, включая конфигурацию дата-центров.¶

messages.getTopReactions #

Получены популярные реакции на сообщения¶

Настройки приватности #

Telegram позволяет пользователям задавать детальные настройки приватности, выбирая, кто может и кто не может взаимодействовать с ними тем или иным способом.¶

Telegram Stories #

Пользователи и каналы Telegram могут без труда публиковать и просматривать истории через API.¶

Подключённые бизнес-боты #

Пользователи могут подключать ботов Telegram, которые будут обрабатывать сообщения и отвечать на них от имени пользователя. Это позволяет легко встроить любые уже существующие инструменты и рабочие процессы или добавить ИИ-помощников, которые ведут их чаты.¶

Mini Apps в Telegram #

Боты могут предлагать пользователям интерактивные веб-приложения на HTML5, полностью заменяющие любой сайт.¶

Темы форума #

Telegram позволяет создавать форумы с несколькими самостоятельными темами.¶

Управляемые боты #

Пользователи могут создавать управляемых ботов (которыми управляет определённый бот-менеджер) прямо через MTProto API, не обращаясь к @BotFather.¶

Гостевой режим для ботов #

Гостевых ботов можно вызывать по имени пользователя из любого несекретного личного чата, группы и супергруппы (кроме групп и супергрупп с включённой защитой контента »); они публикуют свои результаты прямо в чат, даже если не состоят в нём.¶

Эмодзи-статус #

Telegram позволяет пользователям выбрать эмотикон или пользовательский эмодзи в качестве статуса, который отображается рядом с их именем в чатах и профилях.¶

Акцентные цвета #

Пользователи и каналы Telegram могут менять акцентный цвет и фоновый узор страницы своего профиля и своих сообщений!¶

Сторонняя верификация #

Чтобы ещё повысить прозрачность в Telegram, официальные сторонние сервисы могут присваивать аккаунтам пользователей и чатам дополнительные значки верификации — чтобы предотвратить мошенничество и снизить распространение недостоверной информации.¶

Платные сообщения #

Telegram Stars можно использовать для оплаты сообщений пользователям, супергруппам и каналам, в которых настроены платные сообщения: за каждое отправленное им сообщение взимается плата.¶

Telegram Stars #

Telegram Stars — виртуальные предметы, которые позволяют пользователям покупать цифровые товары и услуги у ботов и мини-приложений внутри экосистемы Telegram, отправлять подарки авторам на платформе Telegram и не только.¶

users.getRequirementsToContact #

Проверить, можем ли мы писать указанным пользователям; используется для массовых проверок сообщений только для Premium » и платных сообщений ».¶

Для каждого переданного пользователя возвращает конструктор RequirementToContact (на той же позиции в векторе), содержащий требования для связи с ним.¶
