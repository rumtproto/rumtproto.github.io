SDK для Javascript #

Javascript SDK помогает легко интегрировать запросы Telegram Passport на сайт. Примеры использования этого SDK см. в нашем репозитории GitHub.¶

Установка #

Скачайте и подключите Javascript SDK в разделе head страницы:¶

<script src="telegram-passport.js"></script>

Использование #

Просто вызовите Telegram.Passport.createAuthButton, чтобы создать стандартную кнопку Telegram Passport:¶

<div id="telegram_passport_auth"></div>
<script>
  Telegram.Passport.createAuthButton('telegram_passport_auth', {
    bot_id:       123456, // place id of your bot here
    scope:        {data: [{type: 'id_document', selfie: true}, 'address_document', 'phone_number', 'email'], v: 1},
    public_key:   '-----BEGIN PUBLIC KEY----- ...', // place public key of your bot here
    nonce:        'ab2df83746a87d2f3bd6...', // place nonce here
    callback_url: 'https://example.com/callback/' // place callback url here
  });
</script>

Обратите внимание: при использовании заголовка Content-Security-Policy (CSP) с директивой frame-src/child-src следует разрешить источник tg:, чтобы предотвратить ошибки в некоторых браузерах (например, Firefox)¶

createAuthButton #

Параметры авторизации #

ПолеТипОписание
bot_idIntegerУникальный идентификатор бота
scopePassportScopeОбъект, сериализованный в JSON, с описанием данных, которые вы хотите запросить
public_keyStringОткрытый ключ бота
nonceStringЗаданное ботом одноразовое значение
callback_urlStringНеобязательное поле. URL, на который будет перенаправлен пользователь.

Параметры кнопки авторизации #

ПолеТипОписание
ТекстStringНеобязательное поле. Текст на кнопке. По умолчанию: «Войти через Telegram».
радиусIntegerНеобязательное поле. Радиус кнопки и подсказки в пикселях. По умолчанию: 23.
tooltip_textStringНеобязательное поле. Текст подсказки. По умолчанию: «Пожалуйста, установите Telegram, чтобы использовать эту возможность».
tooltip_positionStringНеобязательное поле. Положение подсказки. Один из вариантов: «top», «bottom», «left», «right». По умолчанию: «bottom».
tooltip_forceBooleanНеобязательное поле. Всегда показывать подсказку. По умолчанию: false.

Можно также создать собственную кнопку. Не забудьте о подсказке. К кнопке следует добавить обработчик onclick, вызывающий метод Telegram.Passport.auth(auth_params, tooltip_toggle);:¶

<button id="telegram_passport_auth">Log In With Telegram</button>
<script>
  var auth_button = document.getElementById('telegram_passport_auth');
  var auth_params = {
    bot_id:        XXXXXX, // place id of your bot here
    scope:         {data: [{type: 'id_document', selfie: true}, 'address_document', 'phone_number', 'email'], v: 1},
    public_key:    '-----BEGIN PUBLIC KEY----- ...', // place public key of your bot here
    nonce:         'ab2df83746a87d2f3bd6...', // place nonce here
    callback_url:  'https://example.com/callback/' // place callback url here
  };
  auth_button.addEventListener('click', function() {
  	Telegram.Passport.auth(auth_params, function(show) {
      if (show) {
        // some code to show tooltip
      } else {
        // some code to hide tooltip
      }
    });
  }, false);
</script>

Получение информации #

Когда пользователь подтверждает запрос нажатием кнопки «Авторизовать», он перенаправляется на URL, указанный в callback_url, с параметром tg_passport=success, а Bot API отправляет боту обновление с полем passport_data, содержащим зашифрованные данные Telegram Passport.¶

Если пользователь отменяет запрос, он перенаправляется на URL, указанный в callback_url, с параметром tg_passport=cancel.¶

Если во время запроса возникает ошибка, пользователь перенаправляется на URL, указанный в callback_url, с параметром tg_passport=error. Параметр error содержит одно из следующих значений: BOT_INVALID, PUBLIC_KEY_REQUIRED, PUBLIC_KEY_INVALID, SCOPE_EMPTY, NONCE_EMPTY.¶
