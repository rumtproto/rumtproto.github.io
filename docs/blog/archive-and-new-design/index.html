Архивированные чаты, новый дизайн и многое другое #

Сегодняшнее обновление даёт инструменты для упорядочивания сообщений с помощью архивированных чатов, новый дизайн на Android и несколько других полезных функций, чтобы использовать мессенджер по максимуму.¶

Всё на своих местах #

Представляем архивированные чаты — новый инструмент для генеральной уборки в списке чатов. Сортируйте активные и неактивные чаты, отделяйте личное от рабочего или отправляйте надоедливые контакты в архив — для эффектной мести!¶

Archiving chats

Проведите влево по чату, чтобы переместить его в папку архивированных чатов. Когда в архивированный чат придёт уведомление, он выйдет из папки и вернётся в список чатов. Чаты с отключёнными уведомлениями останутся в архиве навсегда.¶

Можно скрыть архив, проведя по нему влево. Чтобы снова увидеть его, потяните экран вниз.¶

Hiding the archive

Закрепляйте в архиве неограниченное число чатов, чтобы сообщения оставались в нужном порядке. Если чаты выходят из архива из-за уведомления, их можно снова архивировать, чтобы вернуть на прежнее место в папке.¶

Pinned chats in the archive

Массовые действия для длинного списка чатов #

Время — деньги, а деньги покупают кошачий корм, поэтому не теряйте времени и используйте массовые действия в списке чатов, теперь доступные и в Telegram для Android. Удерживайте чат, чтобы открыть новое меню: в нём можно выбрать несколько чатов, а затем закрепить, отключить уведомления, архивировать или удалить их — быстрее, чем когда-либо.¶
