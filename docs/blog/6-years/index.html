Шесть лет Telegram #

Мы запустили Telegram 6 лет назад, 14 августа 2013 года, — и сразу начали работу над следующим обновлением. С тех пор так и повелось.¶

Вскоре мы заметили, что наша работа не только развивает Telegram, но и приводит к эволюции обмена сообщениями в целом. Приятно видеть, как наши решения и дизайнерские подходы становятся фактическими стандартами повсеместно.¶

Чтобы развлечь вас, пока мы работаем над вторым обновлением этого месяца, мы составили краткую историю Telegram. Она оказалась довольно „огромной“ для „краткой“, но следующее обновление всё равно не завтра. Читайте дальше.¶

И ещё: если хотите сделать нам подарок, приведите сегодня в Telegram двух лучших друзей.¶

Не такая уж краткая история Telegram #

Почему-то мы начали писать это задом наперёд — от последнего обновления к первобытному лету 2013 года. А потом менять порядок было уже поздно: составитель публикации сказал, что объявит голодовку, если мы попытаемся.¶

Так что любителям хронологии лучше перейти в конец и листать оттуда вверх. (Кстати, мы решили поддерживать эту публикацию в актуальном состоянии по мере выхода обновлений.)¶

Telegram поддерживает iPad с сентября 2014 года. В этом обновлении приложение iOS научилось воспроизводить GIF-анимации, получило облачный поиск сообщений и поиск по имени файла в разделе общих документов. iOS также догнала Android, добавив поддержку списков рассылки.¶

В Telegram с сентября 2014 года¶

  • New app: iPad support
  • Send GIFs on iOS
  • Broadcast lists on iOS
  • Large photos in chats
  • Cloud search

август 2014 #

Списки рассылки впервые были представлены в Android в августе 2014, но чуть больше года спустя они были заменены на каналы].¶

В Telegram с августа 2014 года¶

  • Broadcast lists

июнь 2014 #

Multiple photo upload and more¶

Telegram для Android догнал iOS, позволяя пользователям предварительно просматривать фотографии перед отправкой, а также выбирать и отправлять множество фотографий одновременно. Уведомления были улучшены, чтобы сделать их более надежными.¶

В Telegram с июня 2014 года¶

  • Send multiple photos at once
  • Preview photos before sending
  • Improved notifications

Март 2014 #

Voice Messages, Delete Messages for both sides in Secret Chats, Language Settings on Android¶

В обновлении от марта 2014 года в Telegram появились голосовые сообщения. Сообщения, удаленные в секретных чатах, начали исчезать для обеих сторон.¶

В Telegram для Android в настройках появилась возможность изменить язык приложения. Первыми добавленными языками стали немецкий и итальянский.¶

В Telegram с марта 2014 года¶

  • Voice messages
  • Language settings on Android
  • Message deletion for both sides in Secret Chats

Февраль 2014 года #

New apps, autodownload settings and contact management tools for Android¶

Появилось больше приложений Telegram. Было представлено неофициальное приложение Telegram для Web, которое позднее перенесли на web.telegram.org, сделав официальной веб-версией. Telegram для Windows Phone был создан на конкурсе для разработчиков приложений.¶

Тем временем в обновлении для Android появились настройки автозагрузки и новые инструменты управления контактами.¶

В Telegram с февраля 2014 года¶

  • New app: Stand-alone Web version
  • Autodownload settings
  • Contact management tools
  • Windows Phone support

Январь 2014 года #

Send documents and files¶

В начале 2014 года Telegram разрешил отправлять документы любого типа, включая .pdf, .doc, .png, .mp3 и другие. Ограничение размера — 1,5 GB на файл.¶

Было анонсировано неофициальное приложение Telegram для ПК, которое позднее стало официальным Telegram Desktop.¶

В Telegram с января 2014 года¶

  • New app: Stand-alone Desktop app
  • Send documents on iOS and Android
  • Send documents on Telegram Desktop

Декабрь 2013 года #

Crowdsourcing a more secure future¶

Единственная существенная уязвимость, когда-либо обнаруженная в протоколе MTProto, была исправлена во время первого криптографического конкурса Telegram. Исследователь, обнаруживший её, получил вознаграждение $100,000.¶

В Telegram с декабря 2013 года¶

  • Bug bounty program
  • Detailed technical FAQ

Октябрь 2013 года #

После конкурса для разработчиков Android была официально запущена альфа-версия Telegram для Android. В приложениях Telegram появились секретные чаты с таймерами самоуничтожения.¶

Спецификация протокола MTProto и Telegram API были полностью задокументированы, а код приложений стал открытым.¶

В Telegram с октября 2013 года¶

  • End-to-end encrypted chats
  • Self-destruct timers
  • Open source apps
  • Documented protocol and API
