Конкурс на $50,000 для разработчиков Blackberry #

Многие пользователи Telegram просили нас поддержать устройства Blackberry 10. Будучи небольшой командой, мы вынуждены выбирать приоритетные направления. Но поскольку Telegram API на 100% открыт и бесплатен, любой независимый разработчик может портировать Telegram на Blackberry 10, изучив наш протокол и код на Java, используемый в приложении для Android.¶

Чтобы поддержать поклонников Telegram среди разработчиков Blackberry, мы объявляем месячный конкурс программирования, который начинается сегодня. Ваша задача — перенести Telegram на BB 10, используя открытый Java-код приложения для Android. Призовой фонд в $50,000 будет распределён между победителями.¶

Цели #

Разумеется, можно просто скомпилировать наш код для Android для использования на платформе BB, но следует учесть ещё три вещи:¶

  • Нативный дизайн BB. Мы разработали Telegram для BB 10 и предоставляем вам скриншоты и графику, но реализовать его должны вы.
  • Нативные уведомления BB. Мы подготовили для них API; очевидно, в версии для Android их нет.
  • Скорость и стабильность. Наш код для Android не оптимизирован для работы на BB 10, и без рефакторинга он неизбежно будет работать с накладными расходами.
