Telegram Gateway — быстрая, доступная и безопасная верификация пользователей #

Telegram Gateway — выгодное и ориентированное на конфиденциальность решение для аутентификации пользователей, позволяющее компаниям проверять номера телефонов клиентов через Telegram за малую долю стоимости традиционных SMS.¶

Существенно сократите расходы на верификацию #

  • Аутентифицируйте пользователей всего за $0,01 за код верификации — до 50 раз дешевле, чем SMS.
  • Автоматический возврат средств за недоставленные коды — вы платите только за успешные верификации.

Безопасно и надёжно #

  • Использует надёжную инфраструктуру Telegram для быстрой и безопасной доставки кодов.
  • Помогает приложениям избежать устаревших и дорогих методов верификации.

Удобно для разработчиков #

  • Простая интеграция с понятным API.
  • Бесплатная тестовая среда — попробуйте её, прежде чем принимать решение.

FAQ #

В: Кто предоставляет номер телефона пользователей? #

Сервисы, использующие Gateway API, должны указывать соответствующий номер телефона для каждого отправляемого сообщения. Все используемые номера телефонов должны принадлежать пользователям, которые добровольно сообщили свой номер сервису, чтобы получать сообщения на зарегистрированный аккаунт Telegram.¶

Telegram не раскрывает номера телефонов пользователей сервисам, использующим платформу верификации Telegram.¶

Вопрос: должны ли мои пользователи дать согласие на получение моих сообщений? #

Да. Зарегистрированные номера телефонов пользователей Telegram всегда конфиденциальны — поэтому пользователи должны добровольно согласиться, сообщив номер телефона вашему сервису и согласившись получать ваши сообщения в Telegram.¶

В: Какой формат номера телефона следует использовать? #

Все номера телефонов следует указывать в формате E.164.¶

Вопрос: как протестировать мой процесс авторизации? #

Для тестирования Gateway API можно просто отправлять коды на собственный номер телефона в Telegram — все сообщения самому себе бесплатны.¶

В: Можно ли переводить средства между аккаунтами Gateway? #

Нет, перевод средств между аккаунтами платформы верификации сейчас не поддерживается. Все средства, зачисленные на аккаунт, являются предоплаченными кредитами и не могут быть переведены или выведены.¶

Подробнее см. раздел 3.1 Условий использования платформы верификации.¶

В: Как проверить, может ли пользователь получать мои сообщения в Telegram? #

Для проверки возможности получать ваши сообщения в Telegram можно использовать метод checkSendAbility. Если пользователь не может их получать, запрос будет бесплатным.¶

Подробнее о ценообразовании для проверок и фактических запросов рассказано в документации.¶

В: Я только что получил сообщение в чате «Коды верификации». Что это? #

Это означает, что сервис использует Telegram Gateway для отправки кода верификации на ваш номер телефона. Подробнее рассказано в FAQ Telegram.¶
