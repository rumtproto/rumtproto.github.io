Конструкторы #

КонструкторОписание
chatEmptyПустой конструктор, группа не существует
chatИнформация о группе.

При обновлении локальной базы пиров все поля вновь полученного конструктора имеют приоритет над старым конструктором, сохранённым локально (в том числе поля, не заданные в новом конструкторе, удаляются).

chatForbiddenГруппа, к которой у пользователя нет доступа. Например, потому что пользователя исключили из группы.
channel Информация о канале или супергруппе

При обновлении локальной базы пиров все поля вновь полученного конструктора имеют приоритет над старым конструктором, сохранённым локально (в том числе поля, не заданные в новом конструкторе, удаляются).
