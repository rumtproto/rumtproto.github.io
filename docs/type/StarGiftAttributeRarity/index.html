StarGiftAttributeRarity

Тип из схемы TL.

Rarity of a collectible gift » attribute, either as an exact permille value or as one of the named rarity tiers (uncommon, rare, epic, legendary).

Определение TL

starGiftAttributeRarity#36437737 permille:int = StarGiftAttributeRarity;
starGiftAttributeRarityUncommon#dbce6389 = StarGiftAttributeRarity;
starGiftAttributeRarityRare#f08d516b = StarGiftAttributeRarity;
starGiftAttributeRarityEpic#78fbf3a8 = StarGiftAttributeRarity;
starGiftAttributeRarityLegendary#cef7e7a8 = StarGiftAttributeRarity;

Конструкторы

Constructor Описание
starGiftAttributeRarity Exact rarity value for a collectible gift attribute.
starGiftAttributeRarityUncommon Represents uncommon collectible gift attribute rarity.
starGiftAttributeRarityRare Represents rare collectible gift attribute rarity.
starGiftAttributeRarityEpic Represents epic collectible gift attribute rarity.
starGiftAttributeRarityLegendary Represents legendary collectible gift attribute rarity.
