Конструкторы #

КонструкторОписание
keyboardButtonКнопка клавиатуры бота

Доступна только в клавиатурах ответа.

При нажатии клиенты обязаны отправить text в виде сообщения в текущий чат в ответ на сообщение, к которому была прикреплена replyKeyboardMarkup.
keyboardButtonUrlКнопка со ссылкой

Доступна только в инлайн-клавиатурах.

При нажатии клиенты открывают url, показывая запрос подтверждения, если только адрес не является одним из внутренних URI.
keyboardButtonCallbackCallback-кнопка

Доступно только в инлайн-клавиатурах.

При нажатии клиенты отправляют боту data, при необходимости передавая параметры 2FA SRP пользователя для подтверждения личности, как описано в разделе callback-запросов.
keyboardButtonRequestPhoneКнопка для запроса номера телефона пользователя

Доступно только в личных чатах, в клавиатурах ответа.

При нажатии клиенты обязаны запросить у пользователя разрешение на отправку в чат его контакта в ответ на сообщение, к которому была приложена replyKeyboardMarkup.
keyboardButtonRequestGeoLocationКнопка для запроса геолокации пользователя

Доступно только в личных чатах, в клавиатурах ответа.

При нажатии клиенты обязаны запросить у пользователя разрешение на отправку в чат его текущей геолокации в ответ на сообщение, к которому была приложена replyKeyboardMarkup.
keyboardButtonSwitchInlineКнопка для переключения пользователя в инлайн-режим

Доступно только в инлайн-клавиатурах.

При нажатии клиенты обязаны вставить имя пользователя бота и query в поле ввода чата, инициировав инлайн-запрос.

Если установлен same_peer, клиенты используют текущий чат. Иначе клиенты предлагают пользователю выбрать чат, отфильтрованный по peer_types, если он указан.
keyboardButtonGameКнопка для запуска игры

Доступно только в инлайн-клавиатурах.

При нажатии клиенты обязаны открыть игру из приложенного конструктора messageMediaGame, вызвав messages.getBotCallbackAnswer с установленным флагом game, как описано в разделе Запуск игры.
keyboardButtonBuyКнопка для покупки товара

Доступно только в инлайн-клавиатурах.

При нажатии клиенты обязаны начать процесс оплаты по приложенному счёту.
keyboardButtonUrlAuthКнопка для запроса авторизации пользователя через URL с помощью бесшовного входа через Telegram. При нажатии такой кнопки следует вызвать messages.requestUrlAuth, передав button_id и идентификатор сообщения-контейнера. Возвращённый объект urlAuthResultRequest будет содержать подробности запроса авторизации (request_write_access, если бот хочет отправлять пользователю сообщения, а также имя пользователя бота, которое будет использоваться для авторизации пользователя). Наконец, пользователь может вызвать messages.acceptUrlAuth, чтобы получить urlAuthResultAccepted с URL, который следует открыть вместо url этого конструктора, либо urlAuthResultDefault, в случае которого следует открыть url этого конструктора. Если пользователь откажется от запроса авторизации, но всё же захочет открыть ссылку, необходимо использовать url этого конструктора.

Доступно только во встроенных клавиатурах.
inputKeyboardButtonUrlAuthКнопка для запроса авторизации пользователя через URL с помощью бесшовного входа через Telegram.

Используйте этот конструктор, чтобы отправить кнопку keyboardButtonUrlAuth во встроенной клавиатуре.
keyboardButtonRequestPollКнопка для запроса опроса у пользователя

Доступно только в личных чатах, в клавиатурах ответа.

При нажатии клиенты предлагают пользователю создать и отправить опрос в ответ на сообщение, к которому была приложена replyKeyboardMarkup. Если установлен quiz, должно предлагаться создание викторины.
inputKeyboardButtonUserProfileКнопка, ведущая непосредственно в профиль пользователя

Используйте этот конструктор, чтобы отправить кнопку keyboardButtonUserProfile во встроенной клавиатуре.
keyboardButtonUserProfileКнопка, ведущая непосредственно в профиль пользователя

Доступно только в инлайн-клавиатурах.

При нажатии клиенты обязаны открыть профиль пользователя, указанного в user_id.
keyboardButtonWebViewКнопка для открытия mini app бота с помощью messages.requestWebView с передачей сведений о пользователе после его подтверждения.

Может отправляться или приниматься только в составе инлайн-клавиатуры; для клавиатур ответа используйте keyboardButtonSimpleWebView.

При нажатии клиенты обязаны открыть Mini App из инлайн-кнопки с помощью messages.requestWebView, передав url в messages.requestWebView.url.
keyboardButtonSimpleWebViewКнопка для открытия mini app бота с помощью messages.requestSimpleWebView без передачи сведений о пользователе веб-приложению.

Может отправляться или приниматься только в составе клавиатуры ответа; для инлайн-клавиатур используйте keyboardButtonWebView.

При нажатии клиенты обязаны открыть Mini App из кнопки клавиатуры с помощью messages.requestSimpleWebView, передав url в messages.requestSimpleWebView.url.
keyboardButtonRequestPeerПредлагает пользователю выбрать одного или нескольких пиров и передать их боту с помощью messages.sendBotRequestedPeer

Доступно только в личных чатах, в клавиатурах ответа.

Полное описание процесса см. в разделе запросы пиров.
inputKeyboardButtonRequestPeerПредлагает пользователю выбрать и передать боту один или несколько пиров с помощью messages.sendBotRequestedPeer.

Используйте этот конструктор, чтобы отправить кнопку keyboardButtonRequestPeer в клавиатуре ответа в личном чате.

Полный процесс описан в разделе запросы пиров.
keyboardButtonCopyКнопка копирования в буфер обмена

Доступна только в инлайн-клавиатурах.

При нажатии клиенты обязаны скопировать copy_text в буфер обмена.
