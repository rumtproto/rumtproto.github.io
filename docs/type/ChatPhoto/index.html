ChatPhoto

Тип из схемы TL.

Object defines a group profile photo.

Определение TL

chatPhotoEmpty#37c1011c = ChatPhoto;
chatPhoto#1c6e1c11 flags:# has_video:flags.0?true photo_id:long stripped_thumb:flags.1?bytes dc_id:int = ChatPhoto;

Конструкторы

Constructor Описание
chatPhotoEmpty Group photo is not set.
chatPhoto Group profile photo.
Оригинал: https://core.telegram.org/type/ChatPhoto
Неофициальный перевод документации core.telegram.org. Термины сохранены на языке оригинала; права на оригинальные тексты принадлежат Telegram FZ-LLC.
