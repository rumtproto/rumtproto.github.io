WebPage #

Предпросмотр веб-страницы в формате Instant View¶

webPageEmpty#211a1788 flags:# id:long url:flags.0?string = WebPage;
webPagePending#b0d13e47 flags:# id:long url:flags.0?string date:int = WebPage;
webPage#e89c45b2 flags:# has_large_media:flags.13?true video_cover_photo:flags.14?true id:long url:string display_url:string hash:int type:flags.0?string site_name:flags.1?string title:flags.2?string description:flags.3?string photo:flags.4?Photo embed_url:flags.5?string embed_type:flags.5?string embed_width:flags.6?int embed_height:flags.6?int duration:flags.7?int author:flags.8?string document:flags.9?Document cached_page:flags.10?Page attributes:flags.12?Vector<WebPageAttribute> = WebPage;
webPageNotModified#7311ca11 flags:# cached_page_views:flags.0?int = WebPage;

Конструкторы #

КонструкторОписание
webPageEmptyПредпросмотр для этой веб-страницы недоступен
webPagePendingПредпросмотр веб-страницы сейчас создаётся
webPage Предпросмотр веб-страницы

Поле type указывает тип веб-страницы, от которого зависит способ отрисовки предпросмотра (то есть какая дополнительная кнопка действия предлагается, откуда берётся медиа и какой WebPageAttribute присутствует в поле attributes). Возможны следующие значения:



- app - Предпросмотр ссылки на Mini App »: в photo находится значок приложения, а клиенты отображают кнопку, запускающую Mini App ».
- article - Предпросмотр произвольной внешней статьи или веб-страницы. Если задано поле cached_page, клиенты отображают кнопку instant view.
- document - Предпросмотр внешнего документа или файла, содержащегося в поле document.
- gif - Предпросмотр внешней анимации GIF. Если заданы embed_url+embed_type, GIF отрисовывается встроенным проигрывателем, иначе анимация содержится в поле document.
- photo - Предпросмотр внешнего изображения, содержащегося в поле photo.
- profile - Предпросмотр внешней страницы автора или профиля; клиенты обычно отрисовывают его с маленькой миниатюрой (принудительно уменьшенное медиа).
- telegram_aicomposetone - Предпросмотр ссылки на тон ИИ-помощника », которой делятся при показе пользовательского тона ИИ-помощника ». Поле attributes содержит webPageAttributeAiComposeTone с пользовательским эмодзи », представляющим этот тон; клиенты отображают кнопку, применяющую полученный тон.
- telegram_album - Предпросмотр ссылки на сообщение », указывающей на группу сообщений (альбом); отрисовывается как сгруппированный медиа-альбом, а не как предпросмотр с одним медиа. Для этого типа медиа альбома не берутся из полей верхнего уровня photo/document: вместо этого обязательно присутствует cached_page (instant view), и клиенты отрисовывают элементы его первого блока pageBlockCollage или pageBlockSlideshow. Каждый элемент pageBlockPhoto/pageBlockVideo в этом блоке ссылается на изображение или видео по идентификатору, который разрешается по полям photos и documents из cached_page. Сам instant view кнопкой не предлагается (его заменяют медиа альбома).
- telegram_auction - Предпросмотр ссылки на аукцион » для аукциона коллекционных подарков ». Поле attributes содержит webPageAttributeStarGiftAuction с выставленным на аукцион подарком и датой окончания аукциона; клиенты отображают кнопку для участия в аукционе либо для просмотра результатов после его завершения.
- telegram_background - Предпросмотр глубокой ссылки на обои » для обоев чата ». Параметры обоев (цвета фона, поворот градиента, интенсивность узора, размытие/движение и т. д.) разбираются из глубокой ссылки в поле url, а не из отдельных полей. Обои-изображения содержат изображение обоев в поле document. Обои-узоры также используют поле document, причём MIME-типом узора служит application/x-tgwallpattern или image/png; цвета из url отрисовываются как фон и оттенок узора. Одноцветные и градиентные обои не содержат медиа и отрисовываются по цветам, закодированным в url. Поле photo отсутствует. Клиенты отображают кнопку для применения фона.
- telegram_bot - Предпросмотр ссылки на бота »; отрисовывается как предпросмотр профиля с использованием аватара бота в поле photo.
- telegram_botapp - Предпросмотр прямой ссылки на Mini App » для именованного Mini App бота: в photo находится превью приложения, а клиенты отображают кнопку, открывающую Mini App.
- telegram_call - Предпросмотр ссылки на конференцию » для группового звонка/конференции »; клиенты отображают кнопку для присоединения к звонку (поля photo/document отсутствуют).
- telegram_channel - Предпросмотр ссылки на публичное имя пользователя » для канала с использованием аватара канала в поле photo; клиенты отображают кнопку для открытия канала или подписки на него.
- telegram_channel_boost - Предпросмотр ссылки на буст », позволяющей забустить канал », с использованием аватара канала в поле photo; клиенты отображают кнопку для буста канала.
- telegram_channel_direct - Предпросмотр ссылки на монофорум » для личных сообщений канала с использованием аватара канала в поле photo.
- telegram_channel_request - Предпросмотр пригласительной ссылки на чат » для канала, в котором включены заявки на вступление »; клиенты отображают кнопку «Подать заявку».
- telegram_chat - Предпросмотр ссылки на публичное имя пользователя » для обычной группы с использованием аватара группы в поле photo; клиенты отображают кнопку для открытия группы или вступления в неё.
- telegram_chat_request - Предпросмотр пригласительной ссылки на чат » для группы, в которой включены заявки на вступление »; клиенты отображают кнопку «Подать заявку».
- telegram_chatlist - Предпросмотр ссылки на папку чатов » для папки чатов, доступной для распространения » (поля photo/document отсутствуют): клиенты используют для текста предпросмотра поля site_name, title и description, WebPageAttribute не требуется, а кнопка действия открывает глубокую ссылку из url для импорта папки.
- telegram_collection - Предпросмотр ссылки на коллекцию подарков » для коллекции подарков ». Поле attributes содержит webPageAttributeStarGiftCollection со стикерами-значками коллекции; клиенты отображают кнопку для просмотра коллекции.
- telegram_community - Предпросмотр ссылки на папку чатов » для папки чатов, доступной для распространения »; отрисовывается так же, как telegram_chatlist.
- telegram_giftcode - Предпросмотр ссылки на подарочный код Premium » для подарочного кода Telegram Premium »; клиенты отображают кнопку для просмотра или активации подарочного кода (поля photo/document отсутствуют).
- telegram_group_boost - Предпросмотр ссылки на буст », позволяющей забустить супергруппу », с использованием аватара супергруппы в поле photo; клиенты отображают кнопку для буста супергруппы.
- telegram_livestream - Предпросмотр ссылки на видеочат/трансляцию » для прямой видеотрансляции »; отрисовывается как предпросмотр видеочата с пометкой трансляции, клиенты отображают кнопку для просмотра трансляции.
- telegram_megagroup - Предпросмотр ссылки на публичное имя пользователя » для супергруппы с использованием аватара супергруппы в поле photo; клиенты отображают кнопку для открытия супергруппы или вступления в неё.
- telegram_megagroup_request - Предпросмотр пригласительной ссылки на чат » для супергруппы, в которой включены заявки на вступление »; клиенты отображают кнопку «Подать заявку».
- telegram_message - Предпросмотр ссылки на сообщение », указывающей на одно сообщение; клиенты отображают кнопку для открытия сообщения. Поле cached_page с instant view для этого типа игнорируется.
- telegram_newbot - Предпросмотр ссылки на запрос создания управляемого бота », используемой для создания нового бота; клиенты отображают кнопку для создания и регистрации управляемого бота.
- telegram_nft - Предпросмотр ссылки на коллекционный подарок » для коллекционного (уникального) подарка ». Поле attributes содержит webPageAttributeUniqueStarGift с уникальным подарком; клиенты отображают кнопку для просмотра коллекционного подарка.
- telegram_stickerset - Предпросмотр ссылки на набор стикеров » для набора стикеров или пользовательских эмодзи ». Поле attributes содержит webPageAttributeStickerSet с несколькими стикерами для предпросмотра и флагами emojis/text_color; клиенты показывают эти стикеры и отображают кнопку для просмотра набора стикеров (или набора пользовательских эмодзи, если установлен флаг emojis).
- telegram_story - Предпросмотр ссылки на историю » для истории ». Поле attributes содержит webPageAttributeStory с пиром и идентификатором истории (и, необязательно, со встроенным storyItem); медиа и подпись для предпросмотра берутся из истории, а клиенты отображают кнопку для её просмотра.
- telegram_story_album - Предпросмотр ссылки на альбом историй » для альбома историй »: присутствует обложка в поле photo (и, необязательно, видео в поле document), а клиенты отображают кнопку для просмотра альбома историй.
- telegram_theme - Предпросмотр ссылки на тему » для темы оформления ». Поле attributes содержит webPageAttributeTheme с файлами темы и её настройками; клиенты отображают кнопку для применения темы.
- telegram_user - Предпросмотр ссылки на публичное имя пользователя » для пользователя; отрисовывается как предпросмотр профиля с использованием аватара пользователя в поле photo.
- telegram_videochat - Предпросмотр ссылки на видеочат/трансляцию » для видеочата »; отрисовывается как предпросмотр видеочата.
- telegram_voicechat - Предпросмотр ссылки на видеочат/трансляцию » для голосового чата »; отрисовывается как предпросмотр видеочата без видео, клиенты отображают кнопку для присоединения к голосовому чату.
- video - Предпросмотр внешнего видео. Если заданы embed_url+embed_type, видео отрисовывается встроенным проигрывателем, иначе видео содержится в поле document.

webPageNotModifiedПредпросмотр веб-страницы не изменился
