Игровая платформа #

Боты могут предлагать пользователям HTML5-игры для одиночной игры или соревнований друг с другом в группах и личных чатах. Игры — новый тип содержимого в Telegram, который бот может отправлять пользователям.¶

Ознакомьтесь с ботами @gamebot и @gamee, чтобы увидеть примеры возможностей новой игровой платформы.¶

Веб-приложения #

С апреля 2022 года для создания мощных игр на JavaScript также можно использовать Web Apps.¶

Подробнее см. руководство по Web Apps.¶

Создание игры #

Для начала отправьте команду /newgame боту @BotFather. Он запросит текст описания и фотографию. Также можно загрузить необязательную GIF-анимацию, демонстрирующую игру пользователям и делающую сообщения с игрой привлекательнее (примеры см. в Lumberjack или Corsairs).¶

Запуск игры #

После создания игры бот может отправлять её в чаты как обычное сообщение или предлагать через инлайн-режим. В сообщении с игрой всегда будет встроенная инлайн-кнопка «Играть».¶

При нажатии этой кнопки бот получает callback-запрос с указанием запрошенной игры. Бот предоставляет правильный URL для конкретного пользователя, и приложение автоматически открывает игру во встроенном браузере.¶

Добавление кнопок #

Если отправить сообщение с игрой без кнопок, в нём автоматически появится кнопка «Играть в НазваниеИгры». В сообщение с игрой можно вручную добавить несколько кнопок. Обратите внимание: первой кнопкой в первой строке всегда должна быть кнопка запуска игры. Можно добавить и другие кнопки — например, с описанием правил или ссылкой на официальное сообщество игры.¶

Отслеживание рекордов #

В сообщении с игрой также отображаются рекорды для текущего чата. При установке нового рекорда в чат отправляется сервисное сообщение, а сообщение с текущей таблицей результатов обновляется. Также можно запросить необходимые данные для создания внутриигровых таблиц рекордов.¶

Публикация игры в чатах Telegram #

Есть много способов, которыми пользователи могут вирусно распространять понравившуюся игру. В интерфейсе всегда есть стандартная системная кнопка для публикации игры в правом верхнем углу:¶

Стандартная кнопка «Поделиться»: iOS Стандартная кнопка «Поделиться»: Android¶

Также на HTML-странице можно создать дополнительную кнопку «Поделиться». При её нажатии игра отправляется в выбранный чат вместе с лучшим результатом пользователя в игре.¶

Gamee: кнопка «Поделиться» Отправленная игра с отметкой «только что набрал очки»¶

Чтобы добавить кнопку публикации, включите этот скрипт в конце тега <body> на странице:¶

<script src="https://telegram.org/js/games.js"></script>

Затем используйте метод TelegramGameProxy.shareScore() для вызова функции публикации.¶

Предупреждение: не вызывайте этот метод без согласия и прямого действия пользователя.¶

Пример:¶

<button onclick="TelegramGameProxy.shareScore()">Share score</button>

Эта библиотека работает только при запуске из Telegram, поэтому не используйте её на обычных веб-страницах.¶

Использование параметров URL #

Если URL использует идентификатор фрагмента, учтите, что приложения Telegram могут добавлять к идентификатору фрагмента некоторые служебные параметры. Имена таких параметров начинаются с tg (код, добавляющий их, можно посмотреть здесь). Если нужно прочитать собственные параметры из идентификатора фрагмента, используйте объект TelegramGameProxy.initParams.¶

Создание качественного HTML5-интерфейса #

Убедитесь, что HTML5-страница адаптивна и хорошо работает во всех приложениях Telegram и на поддерживаемых платформах. Если невозможно поддержать определённые условия или платформы, не оставляйте пользователей без ответа и хотя бы покажите уведомление.¶
