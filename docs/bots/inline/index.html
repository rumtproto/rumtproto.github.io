Инлайн-боты #

Помимо отправки команд в личных сообщениях или группах, пользователи могут взаимодействовать с ботом через инлайн-запросы. Если инлайн-запросы включены, пользователи могут вызвать бота, введя его имя пользователя и запрос в поле ввода текста в любом чате. Запрос передаётся боту в обновлении. Так люди могут запрашивать содержимое у бота в любом из своих чатов, групп или каналов, вообще не отправляя сообщений.¶

Чтобы включить эту возможность, отправьте команду /setinline боту @BotFather и укажите текст-заполнитель, который пользователь увидит в поле ввода после ввода имени бота.¶

Сведения о соответствующих методах и объектах приведены в руководстве Bot API.¶

Инлайн-результаты #

Инлайн-боты поддерживают все типы содержимого, доступные в Telegram (всего 20). Они могут отправлять стикеры, видео, музыку, геопозиции, документы и многое другое.¶

Клиенты могут отображать результаты с вертикальной или горизонтальной прокруткой в зависимости от типа содержимого:¶

Вертикальная прокрутка Горизонтальная прокрутка¶

Как только пользователь нажимает элемент, он сразу отправляется получателю, а поле ввода очищается.¶

Переключение между инлайн-режимом и личными сообщениями #

Некоторым инлайн-ботам полезна первоначальная настройка, например подключение к аккаунту внешнего сервиса (например, YouTube). Мы добавили простой способ переключаться между личным чатом с ботом и любым чатом, в котором пользователь хочет поделиться инлайн-результатами.¶

Над инлайн-результатами (или вместо них) можно отобразить специальную кнопку «Перейти в личные сообщения». Эта кнопка откроет личный чат с ботом и передаст выбранный вами параметр, чтобы можно было предложить пользователю выполнить необходимые настройки. После этого можно использовать инлайн-клавиатуру с кнопкой switch_inline_query, чтобы вернуть пользователя в исходный чат.¶

Примеры ботов
@youtube — показывает кнопку «Войти в YouTube», затем предлагает персонализированные результаты.¶

Результаты с учётом местоположения #

Инлайн-боты могут запрашивать у пользователей данные геолокации. Чтобы включить это, используйте команду /setinlinegeo с @BotFather. Бот будет запрашивать у пользователя разрешение на доступ к местоположению всякий раз, когда тот отправляет инлайн-запрос.¶

Пример бота
@foursquare — этот бот запросит разрешение на доступ к местоположению пользователя, а затем предоставит результаты с учётом географической привязки.¶

Вирусное распространение #

Рядом с именем отправителя в сообщениях, отправленных с помощью бота, отображается его имя пользователя.¶

GIF, отправленная через бота Подсказки инлайн-ботов¶

Когда пользователь нажимает имя пользователя бота в заголовке сообщения, упоминание автоматически вставляется в поле ввода. При вводе символа @ в поле ввода появляется список подсказок, включающий недавно использованных инлайн-ботов.¶

Сбор обратной связи #

Чтобы знать, какие из предложенных результатов пользователи отправляют собеседникам, отправьте боту @Botfather команду /setinlinefeedback. После включения этой возможности вы будете получать обновления о результатах, выбранных пользователями.¶

Учтите, что для популярных ботов это может создавать проблемы с нагрузкой: из-за кэширования вы можете получать больше результатов, чем фактических запросов (см. параметр cache_time в answerInlineQuery). В таких случаях рекомендуем настроить вероятность получения 1/10, 1/100 или 1/1000 результатов.¶

Примеры инлайн-ботов #

Вот несколько примеров инлайн-ботов, если хотите увидеть их в действии. Попробуйте любого из них:

@vid — поиск видео
@pic — поиск изображений Яндекса
@bing — поиск изображений Bing
@wiki — поиск в Википедии
@imdb — поиск в IMDB
@bold — сделать текст жирным, курсивным или моноширинным¶

@sticker — находить и отправлять стикеры по эмодзи¶
