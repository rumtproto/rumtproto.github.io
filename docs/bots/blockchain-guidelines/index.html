Рекомендации по блокчейну #

Условия использования #

Условия использования для разработчиков ботов разрешают мини-приложениям интегрировать технологию блокчейна при условии, что реализация разработчика:¶

  • Использует блокчейн TON исключительно для создания и распространения криптовалютных токенов или блокчейн-активов.
  • Взаимодействует только с криптовалютными кошельками, подключёнными посредством SDK TON Connect.
  • Не продвигает криптовалютные кошельки, кроме кошельков, основанных на блокчейне TON, использующих TON Connect исключительно для взаимодействия с приложениями и преимущественно предоставляющих услуги, связанные с блокчейном TON.

Важно: чтобы пользователи Telegram сохраняли бесперебойный доступ к своим Mini Apps, разработчики обязаны обеспечить соблюдение пунктов 7.1–7.4 Условий использования до 1 февраля 2025 года.¶

Существующие Mini Apps, работающие на других блокчейнах, обязаны перейти на TON до 21 февраля 2025 года, в том числе перевести существующие активы через мост, мигрировать смарт-контракты и использовать исключительно TON Connect.¶

Пункт 7.1 Условий использования немедленно применяется ко всем новым инициативам на основе блокчейна, включая выпуск новых блокчейн-активов. Все активы, выпущенные или распространённые 21 января 2025 года или позднее, должны ему соответствовать.¶

Боты без Mini Apps #

Для ясности: эти правила применяются только к Mini Apps и их ботам на платформе Telegram. Обычные боты Telegram, не имеющие компонента Mini App, освобождены от их соблюдения.¶

Рекомендации для Mini App #

Чтобы помочь разработчикам при изменении приложений, ниже приведены примеры функций мини-приложений, разрешённых или запрещённых разделом 7 Условий использования, при условии соблюдения всех остальных разделов, включая раздел 9.¶

Блокчейн-активы #

Разрешено:¶

Выпускать или распространять криптовалютные активы в блокчейне TON.¶

  • Разрешены токены на основе TON из игр или коллекционные NFT.

Запрещено:¶

Выпускать или распространять криптовалютные активы или NFT в других блокчейнах.¶

  • Токены и NFT в других блокчейнах, таких как Ethereum, BNB и т. д., запрещены.

Подключение через TON Connect #

Разрешено:
Использовать TON Connect для взаимодействия с кошельком пользователя.¶

  • Использовать TON Connect для подписания транзакции в приложении.
  • Подключать мультичейн-кошелёк через TON Connect для подписания транзакции.

Разрешать другие протоколы подключения кошельков, предназначенные для перевода активов через мост.¶

  • Подключать кошелёк Bitcoin для перевода BTC через мост из сети Bitcoin в блокчейн TON.

Запрещено:
Использовать другие протоколы подключения кошельков вне сценариев перевода через мост.¶

  • Подключать кошелёк Ethereum для подписания транзакции в приложении.
  • Изменять или форкать SDK TON Connect.
  • Ограничивать выбор кошельков в TON Connect, кроме случаев, когда это обусловлено доступностью функций.

Продвижение кошельков и токенов #

Разрешено:
Продвигать кошельки на основе TON в мини-приложениях.¶

  • Вознаграждать пользователей за подключение кошелька на основе TON, преимущественно предназначенного для управления активами в блокчейне TON, например Wallet, Tonkeeper или MyTonWallet.

Продвигать токены на основе TON в официальном канале или сообществе мини-приложения.¶

  • Информировать пользователей о предстоящем запуске нового токена в блокчейне TON.
  • Направлять пользователей на лицензированную биржу, где размещён ваш токен на основе TON.

Запрещено:
Продвигать другие блокчейны, криптоактивы, кошельки или мультичейн-кошельки, основанные на блокчейнах, отличных от TON.¶

  • Вознаграждать пользователей за подключение кошелька из таких блокчейнов, как Ethereum, Bitcoin и т. д.
  • Направлять пользователей на внешние платформы или сайты либо давать на них ссылки, если там продвигаются или используются криптоактивы, не основанные на TON.

Продвигать токены из других блокчейнов в официальном канале или сообществе мини-приложения.¶

  • Информировать пользователей о предстоящем запуске нового токена в другом блокчейне.
  • Рекламировать альтернативные версии токенов на основе TON, основанные на других блокчейнах.

Рекомендации для кошельков #

Ниже приведены дополнительные примеры специально для мини-приложений, которые преимущественно работают как криптовалютный кошелёк.¶

Управление активами #

Разрешено:
Разрешать пользователям управлять активами из других блокчейнов в интерфейсе кошелька.¶

  • Мультичейн-кошельки TON, позволяющие пользователям отправлять и получать Bitcoin, Ethereum и другие криптовалюты.
  • Мультичейн-кошельки TON, предлагающие программы стейкинга для таких токенов, как Bitcoin, Ethereum и другие криптовалюты.
  • Мультичейн-кошельки TON, позволяющие обменивать токены между блокчейнами в интерфейсе своего приложения.

Запрещено:
Разрешать пользователям управлять активами из других блокчейнов, подключаясь к внешним приложениям.¶

  • Использовать встроенный каталог приложений из других блокчейнов в мультичейн-кошельке.
  • Давать ссылки на внешние приложения для управления активами из других блокчейнов.

Подключение кошелька #

Разрешено:
Подключать кошельки через TON Connect.¶

  • Мультичейн-кошелёк, взаимодействующий с приложениями только через TON Connect.

Не предоставлять возможности подключить кошелёк.¶

  • Кошелёк, не предоставляющий подключения к другим приложениям.
  • Мультичейн-кошелёк, позволяющий пользователям стейкать Ethereum в кошельке, не выходя из мини-приложения.

Запрещено:
Подписывать транзакции в других блокчейнах в приложениях вне разрешённых сценариев перевода через мост.¶

  • Кошелёк со встроенным каталогом приложений, использующих другие блокчейны.
  • Кошелёк, интегрирующий другие протоколы подключения кошельков.
