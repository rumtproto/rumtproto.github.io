Ввод данных #

Пользователи могут отправлять ботам сообщения всех типов, включая текст, файлы, геопозиции, стикеры, голосовые сообщения и даже кубики, если хотят испытать удачу. Однако Telegram-боты предлагают множество других инструментов для создания гибких интерфейсов под конкретные потребности:¶

  • Команды, которые выделяются в сообщениях и выбираются из списка после ввода /.
  • Клавиатуры, заменяющие клавиатуру пользователя заранее заданными вариантами ответа.
  • Кнопки, отображаемые рядом с сообщениями бота.

Для ещё большей гибкости Web Apps поддерживают полностью настраиваемые интерфейсы на JavaScript.¶

Примечание: Telegram-боты могут поддерживать несколько языков, адаптируясь к языковым настройкам пользователей в приложении.¶

Команды #

Команда — это простой /keyword, указывающий боту, что делать. Приложения Telegram будут:¶

  • Выделять команды в сообщениях. При нажатии пользователем на выделенную команду она немедленно отправляется снова.
  • Предлагать список поддерживаемых команд с описаниями, когда пользователь вводит / (для этого необходимо передать список команд @BotFather или через соответствующий метод API). Выбор команды из списка немедленно отправляет её.
  • Показывать кнопку меню, содержащую все или некоторые команды бота (настраиваемые через @BotFather).

Команды всегда должны начинаться с символа / и содержать не более 32 символов. В них можно использовать латинские буквы, цифры и подчёркивания, однако для более аккуратного вида рекомендуется простой текст в нижнем регистре.¶

Вот несколько примеров:¶

  • /next — перейти далее
  • /cancel — отменить
  • /newlocation — новое место
  • /newrule — новое правило

Команды должны быть максимально конкретными — например, /newlocation или /newrule лучше, чем команда /new, требующая затем дополнительного параметра от пользователя, такого как "location“ или ”rule".¶

Мы требуем от всех разработчиков поддержки нескольких глобальных команд, чтобы Telegram-боты обеспечивали единообразный и удобный пользовательский опыт.¶

Области действия команд #

Ваш бот может показывать разные команды разным пользователям и группам — это управляется с помощью областей действия. Например, бот может показывать дополнительные команды администраторам групп или переводить список на основе language_code пользователя.¶

Помните, что обновления Bot API не содержат информации об области действия команды, отправленной пользователем; более того, они могут содержать команды, которых в вашем боте вообще нет. Ваш бэкенд должен всегда проверять корректность полученных команд и наличие у пользователя прав на их использование независимо от области действия.¶

Боты с включённым режимом приватности получают команды в группах только при особых условиях — см. здесь.¶

Клавиатуры #

Боты могут обрабатывать произвольный текст пользователя, но предоставление конкретных вариантов часто интуитивнее — здесь особенно полезны пользовательские клавиатуры.¶

При каждой отправке сообщения бот может показывать специальную клавиатуру с заданными вариантами ответа (см. ReplyKeyboardMarkup). Приложения Telegram, получившие сообщение, отобразят эту клавиатуру пользователю. Нажатие любой кнопки немедленно отправит соответствующий текст. Так можно существенно упростить и оптимизировать взаимодействие пользователя с ботом.¶

Используйте параметр one_time_keyboard, чтобы автоматически скрывать клавиатуру бота сразу после её использования.¶

Можно также настроить текст заполнителя в поле ввода, задав параметр input_field_placeholder.¶

Инлайн-клавиатуры #

Иногда требуется выполнить действие без отправки сообщений в чат — например, когда пользователь меняет настройки, переключает параметры или просматривает результаты поиска. В таких случаях можно использовать инлайн-клавиатуры, которые отображаются непосредственно под соответствующими сообщениями.¶

В отличие от пользовательских клавиатур ответа, нажатие кнопок инлайн-клавиатуры не отправляет сообщения в чат. Вместо этого они поддерживают кнопки, работающие в фоновом режиме или открывающие разные интерфейсы: callback-кнопки, URL-кнопки, кнопки переключения в инлайн-режим, игровые кнопки и платёжные кнопки.¶

Для лучшего пользовательского опыта рассмотрите изменение клавиатуры, когда пользователь переключает кнопку настройки или переходит на новую страницу: это быстрее и плавнее, чем отправлять новое сообщение и удалять предыдущее.¶

Кнопка меню #

Во всех чатах с ботами рядом с полем сообщения отображается кнопка меню. По умолчанию нажатие этой кнопки открывает меню, содержащее часть или все команды бота с краткими описаниями. Пользователи могут выбрать команду из меню, не вводя её вручную.¶

Для разных отдельных пользователей или групп пользователей можно задавать разный текст кнопки меню и описаний команд — например, показывать перевод в соответствии с языком пользователя, как описано здесь.¶

Глобальные команды #

Чтобы сделать базовые взаимодействия единообразнее, мы просим всех разработчиков поддерживать несколько основных команд. В приложениях Telegram для них будут ярлыки интерфейса.¶

  • /start — начинает взаимодействие с пользователем, например отправляет вводное сообщение. Эта команда также используется для передачи боту дополнительных параметров (см. глубокие ссылки).
  • /help — возвращает справочное сообщение: краткий текст о возможностях бота и список команд.
  • /settings — (если применимо) показывает настройки бота для этого пользователя и предлагает команды для их изменения.

При первом открытии чата с ботом пользователи увидят кнопку Start. Ссылки Help и Settings будут доступны в меню на странице профиля бота, если добавить их в @BotFather.¶

Выбор чата и пользователя #

Боты могут предоставлять пользователю удобный и интуитивно понятный интерфейс со списком любого числа групп, каналов или других пользователей по заданному набору критериев. Нажатие на чат отправит его идентификатор боту в сервисном сообщении и плавно закроет интерфейс.¶

Бот для управления группами — идеальный пример: администратор может выбрать чат, которым должен управлять бот, а затем пользователя, которого следует повысить — и всё это без ввода текста.¶

Вот краткое руководство по использованию этой возможности:¶

  • Выберите набор критериев и сохраните их в объекте KeyboardButtonRequestChat (либо KeyboardButtonRequestUser для пользователей).
  • Создайте KeyboardButton и сохраните критерии соответственно в request_chat или request_user.
  • Отправьте ReplyKeyboardMarkup, содержащий только что созданную кнопку.
  • Когда пользователь выберет чат, вы получите его идентификатор в сервисном сообщении chat_shared или user_shared.
Video

Учтите, что бот может не суметь использовать полученный идентификатор, если соответствующий чат или пользователь ещё неизвестен либо недоступен другим способом.¶

Взаимодействия #

Помимо отправки команд и сообщений в чат с ботом, есть несколько способов взаимодействовать с ними, не открывая конкретный чат или группу.¶

  • Инлайн-режим позволяет отправлять запросы ботам прямо из поля ввода — из любого чата Telegram.
  • Глубокие ссылки позволяют использовать специальные ссылки, передающие боту определённые параметры при открытии.
  • Интеграция с меню вложений позволяет использовать ботов из меню вложений в чатах.

Инлайн-запросы #

Пользователи могут взаимодействовать с ботом через инлайн-запросы прямо из поля сообщения в любом чате. Для этого достаточно начать сообщение с @username бота и ввести ключевое слово.¶

Получив запрос, бот может вернуть результаты. Как только пользователь выберет один из них, он будет отправлен в соответствующий чат. Так пользователи могут запрашивать и отправлять контент бота в любых своих чатах, группах или каналах.¶

Помните, что инлайн-функциональность должна быть включена через @BotFather, иначе бот не будет получать инлайн-обновления.¶

Примеры инлайн-ботов: @gif, @bing и @wiki. Ботов Web App также можно использовать в инлайн-режиме — попробуйте ввести @durgerkingbot в любом чате.¶

Глубокие ссылки #

Telegram-боты поддерживают механизм глубоких ссылок, позволяющий передавать боту дополнительные параметры при запуске. Это может быть команда для запуска бота или токен аутентификации для привязки аккаунта Telegram пользователя к его аккаунту на другой платформе.¶

У каждого бота есть ссылка, открывающая диалог с ним в Telegram: https://t.me/<bot_username>. В неё можно добавить параметры, чтобы бот сразу работал с дополнительной информацией без участия пользователя.¶

Допускаются A-Z, a-z, 0-9, _ и -. Для кодирования параметров с двоичным и другим содержимым рекомендуется base64url. Длина параметра — до 64 символов.¶

Личные чаты
В личных чатах можно использовать параметр start, чтобы автоматически передавать боту любое значение, когда пользователь нажимает ссылку. Например:¶

https://t.me/your_bot?start=airplane

Когда кто-либо откроет чат с ботом по этой ссылке, вы получите:¶

/start airplane

Группы
В группах к этой ссылке можно добавить параметр startgroup. Например:¶

https://t.me/your_bot?startgroup=spaceship

Переход по ссылке с этим параметром предложит пользователю выбрать группу для добавления бота — полученное обновление будет содержать текст вида:¶

/start@your_bot spaceship

Web Apps также поддерживают глубокие ссылки; подробности — в специальном руководстве.¶

Временные сообщения #

Временные сообщения позволяют ботам отправлять приватные ответы внутри групповых чатов, видимые только конкретному пользователю и боту. Они подходят для приветствий, шёпотов, персонализированных сводок, контекстных подсказок и иных взаимодействий, которые не должны загромождать беседу для остальных.¶

Боты также могут отвечать на временные сообщения или удалять их до истечения срока действия.¶

Поддержка мультимедиа
Временные ответы не ограничены обычным текстом. Боты могут конфиденциально отправлять в группе разнообразный контент, включая:¶

  • Медиа и выражения: фотографии, видео, анимации, аудиофайлы, голосовые сообщения и стикеры.
  • Утилиты и геопозиция: документы, контакты, геопозиции и места.

Двусторонняя приватность с временными командами
Помимо приватных сообщений ботов, пользователи могут отправлять ботам временные команды. Если команда настроена как временная, исходное сообщение пользователя полностью невидимо другим участникам группы и ботам, что позволяет незаметно взаимодействовать в публичных пространствах.¶

Клиенты Telegram визуально выделяют временные команды ботов.¶

Интеграция #

Существуют различные способы дальнейшей интеграции ботов с Telegram и другими сервисами.¶

  • Используйте Web Apps для замены любого веб-сайта.
  • Создавайте инструменты и интегрируйте бизнес-сервисы.
  • Принимайте платежи через сторонних платёжных провайдеров, поддерживающих интеграцию с ботами и Mini Apps.
  • Подключайтесь к Telegram с помощью функции веб-входа.
  • Создавайте игровых ботов, интегрируя HTML5-игры.
  • Помогайте пользователям создавать и управлять стикерами Telegram.

Монетизация #

Telegram предлагает развитую экосистему функций монетизации, позволяющую любому боту поддерживать своё развитие за счёт нескольких источников дохода.¶

Telegram Stars #

Telegram Stars обеспечивают все цифровые транзакции между ботами и пользователями. Пользователи могут приобретать Stars через встроенные покупки в Apple и Google либо через @PremiumBot.¶

Боты могут использовать полученные Stars, чтобы увеличить лимиты сообщений, отправлять подарки пользователям или получать вознаграждения в Toncoin.¶

Цифровые продукты #

Сервисы могут использовать бота для продажи цифровых товаров и услуг: онлайн-курсов, заказных работ и предметов в играх.¶

Мини-приложения #

Mini Apps позволяют разработчикам создавать бесконечно гибкие интерфейсы, запускаемые прямо внутри Telegram, — они органично интегрируются с приложением и заменяют любой веб-сайт.¶

Если бот является мини-приложением, в его профиль можно добавить заметную кнопку Launch app, демонстрационные видео и скриншоты. Для этого перейдите в @BotFather и настройте Main Mini App бота.¶

Мини-приложения подробно описаны в специальном руководстве; внимательно прочитайте его, чтобы узнать о множестве их возможностей.¶

Video

Если вы разрабатываете мини-приложение, обязательно следуйте рекомендациям по дизайну: ваш интерфейс должен органично интегрироваться в приложение, обеспечивая пользователям наилучший опыт.¶

Органичная интеграция с Telegram #

Мини-приложения органично интегрируются с Telegram: от получения подробных настроек темы до использования системных диалогов для считывания QR-кодов, управления биометрией, публикации медиа непосредственно в истории и многого другого.¶

При открытии по прямой ссылке в группе мини-приложения также могут использовать параметр chat_instance для отслеживания текущего контекста и поддерживать совместное использование несколькими участниками чата: для создания интерактивных досок, групповых заказов, многопользовательских игр и многого другого.¶

Предпросмотры Mini App #

Разработчики могут загружать скриншоты и демонстрационные видео мини-приложения прямо со страницы профиля бота, знакомя пользователей с его возможностями и функциями. Эти медиа-предпросмотры показываются каждому пользователю, который просматривает приложение, например в магазине Mini App или через поиск.¶

Предпросмотры поддерживают несколько языков, поэтому можно загружать их переведённые версии, показываемые пользователям в зависимости от языка приложения.¶

Магазин Mini App #

Более 500 миллионов из 950 миллионов пользователей Telegram ежемесячно взаимодействуют с мини-приложениями. Успешные мини-приложения могут быть выделены в магазине Telegram Mini App и появиться у всех пользователей на вкладке «Apps» поиска.¶

Рекомендуемые мини-приложения выбираются по тому, как они обогащают экосистему Telegram. Чтобы повысить шансы, необходимо включить Main Mini App в @BotFather, загрузить в профиль бота качественные медиа-демонстрации приложения и принимать платежи в Telegram Stars.¶

Боты-секретари #

Боты могут включить режим секретаря, позволяющий пользователям подключать их к своей учётной записи и разрешать обрабатывать входящие сообщения и даже отвечать от их имени.¶

Владелец учётной записи может указать, к каким чатам получит доступ ваш бот. В этих чатах бот будет получать все обновления, обычно поддерживаемые Bot API, кроме сообщений, отправленных им самим и другими ботами. В зависимости от настроек подключения бот также может отправлять сообщения и выполнять другие действия от имени владельца учётной записи в чатах, активных за последние 24 часа.¶

TITLE

Краткое руководство по подключению вашего бота к учётным записям пользователей:¶

  • Включите для своего бота режим секретаря в @BotFather.
  • Обрабатывайте входящие обновления BusinessConnection, сообщающие, что пользователь установил, изменил или завершил бизнес-подключение к вашему боту.
  • Обрабатывайте деловые сообщения, обрабатывая обновления business_message, edited_business_message и deleted_business_messages.
  • Проверяйте право бота на отправку сообщений по полю can_reply в последнем обновлении BusinessConnection.
  • Если это разрешено, используйте поле business_connection_id в методах sendMessage, sendChatAction и других методах отправки, чтобы общаться от имени бизнес-пользователя.

Пользователи, которые подключат вашего бота к своей учётной записи, увидят панель быстрых действий вверху каждого управляемого чата. Нажатие «Управление ботом» перенаправит их к вашему боту, который получит сообщение по глубокой ссылке в формате /start bizChat<user_chat_id>.¶

Учтите, что работа ботов в Telegram регулируется Условиями обслуживания для разработчиков ботов Telegram. В частности, для Telegram Business убедитесь, что вы прочитали и поняли раздел 5.4.¶

Создание собственного бота для управления #

Чтобы создать собственного управляющего бота, выполните следующее:¶

  1. Выберите одного из существующих ботов или создайте нового бота через @BotFather.
  2. Откройте настройки бота в MiniApp BotFather и включите «режим управления ботами».

Предоставление доступа к вашему боту для управления #

После включения вы сможете разрешить другим использовать вашего бота для создания собственных ботов и управления ими.¶

Для этого отправьте пользователям ссылку в следующем формате:¶

https://t.me/newbot/{manager_bot_username}/{new_username}?name={new_name}

Например, если созданный вами бот называется @ManagerBot, ссылка может выглядеть так: new_username — предлагаемое имя пользователя для нового бота, а new_name — предлагаемое отображаемое имя.¶

https://t.me/newbot/ManagerBot/CoolAIAgentBot?name=Cool+AI+Agent

Когда пользователь откроет ссылку, появится окно завершения создания бота: его @имя пользователя и отображаемое имя будут заполнены заранее, но их можно изменить.¶

Использование вашего бота для управления #

После подтверждения данных пользователем бот будет создан:¶

  • Ваш @ManagerBot получает обновление managed_bot с объектом ManagedBotUpdated.
  • Этот объект содержит основную информацию о новом боте и его создателе.
  • Чтобы получить токен доступа бота, используйте метод Bot API getManagedBotToken.
  • Затем вы сможете управлять новым ботом через Bot API, получать сообщения и отвечать на них, изменять его профиль, настройки и другое.

Бот-то-Бот Соммунисатион #

В Telegram боты обычно не видят сообщения других ботов. Однако в определённых контекстах общение между ботами разрешено — это открывает сложные сценарии взаимодействия агентов и возможности на основе ИИ.¶

Независимо от контекста, чтобы полностью использовать эту возможность, убедитесь, что для вашего бота в @BotFather включён режим общения между ботами.¶

Общение в групповых чатах #

Бот может взаимодействовать с другим ботом в одной группе следующим образом:¶

  • Упоминание его в команде: /command@OtherBot.
  • Напрямую отвечая на сообщение бота.

Если хотя бы у одного из ботов включён режим общения между ботами, бот-получатель получит сообщение и сможет ответить.¶

Кроме того, боты с включённым режимом общения между ботами будут получать все сообщения других ботов в группах без явных упоминаний или ответов, если они:¶

  • имеют права администратора в группе, или
  • Отключить режим приватности в группах

Пример
Бот-участник может запросить проверку кода у бота-рецензента и обрабатывать отзыв прямо в группе — при необходимости под контролем человека.¶

Взаимодействие в личных чатах #

Боты могут отправлять личные сообщения другим ботам, передавая их @username методу sendMessage.¶

Для этого режим общения между ботами должен быть включён и у отправителя, и у получателя сообщения.¶

Пример
Два бота с ИИ-агентами могут координироваться напрямую через личные сообщения, чтобы организовать сложный многошаговый сценарий.¶

Взаимодействие через бизнес-аккаунты #

Если бот подключён к бизнес-учётной записи с помощью режима доступа к чатам, он может отправлять сообщения другим ботам, используемым этой бизнес-учётной записью.¶

Для этого у бота, отправляющего сообщения, должен быть включён режим общения между ботами.¶

Пример
Использование другого бота в качестве инструмента в бизнес-процессах — для бронирования, обработки запросов клиентов или выполнения сложных задач от имени пользователя.¶

Требования для предотвращения циклов #

Общение между ботами может легко привести к бесконечным циклам взаимодействия. Включая эту функцию, необходимо предусмотреть меры защиты, гарантирующие завершение взаимодействий.¶

Рекомендуемые меры защиты¶

  • Отсеивайте повторяющиеся сообщения.
  • Применяйте ограничения частоты запросов (например, не более одного ответа от каждого бота за несколько секунд).
  • Устанавливайте максимальную глубину взаимодействия или тайм-ауты как глобально, так и для каждого отправителя и получателя.

⚠️ Важно
Ваш бот должен оставаться стабильным, даже если другой бот намеренно отвечает мгновенно и непрерывно.
Ненадлежащая обработка циклов может привести к снижению производительности или ограничениям платформы.¶

Гостевые боты #

Боты Telegram могут включить гостевой режим, чтобы легко взаимодействовать с пользователями в любой группе или личном чате Telegram. Это позволяет интегрировать полезные функции без необходимости управлять чатом или получать доступ к истории сообщений.¶

Гостевые боты

Чтобы включить эту функцию, откройте настройки своего бота в MiniApp BotFather и включите «гостевой режим».¶

Взаимодействия с гостями #

Когда пользователь упоминает гостевого бота (например, @botname) в поддерживаемом чате или отвечает на одно из его сообщений, бот получает специальное обновление и может отправить один ответ. Это позволяет боту:¶

  • Получать контекст из специального обновления, содержащего сообщение с вызовом и, если есть, конкретное сообщение, на которое был дан ответ.
  • Отвечать напрямую сообщением в чат, где произошло взаимодействие, даже не являясь его участником.

Гостевой режим не предоставляет доступа к истории сообщений чата или списку участников. Гостевой бот также не будет получать обновления о будущих сообщениях в чате, пока его вновь не упомянут или напрямую не ответят на его сообщение.¶

В одном сообщении можно одновременно упомянуть до 3 гостевых ботов, что позволяет создавать более сложные или совместные сценарии с агентами.¶

Сценарии использования: гостевой режим и инлайн-режим #

Боты Telegram также поддерживают инлайн-режим, позволяющий отправлять запросы ботам прямо из поля ввода в любом чате Telegram.¶

Разница в том, что инлайн-режим предназначен для получения или доступа к контенту через бота (например, GIF, цитатам, статьям), чтобы отправить его самостоятельно одним нажатием, тогда как гостевой режим позволяет боту активно участвовать и самостоятельно отвечать от своего имени в любом чате с учётом соответствующего контекста.¶

Гостевой режим идеально подходит для:¶

  • ИИ-помощников: вызова агента, который ответит на конкретный вопрос или выполнит задачу, сообщая о ходе работы в чат или группу.
  • Контекстных инструментов: перевода, проверки фактов и подобных утилит, зависящих от контекста или выполняющих несколько шагов.
  • Временной функции: кратковременного добавления возможностей бота в чат без засорения списка участников, раскрытия сообщений или предоставления каких-либо разрешений.

Инлайн-режим идеально подходит для:¶

  • Поиска и отправки: поиска и мгновенной отправки контента (например, попробуйте @gif или @pic) без выхода из текущего чата.
  • Быстрых утилит: получения вычислений, форматирования текста или оперативной проверки статистики.
  • Гибких вложений: использования инлайн-Mini Apps (например, попробуйте @durgerkingbot) для прикрепления или быстрого доступа к интерактивным меню, сложным интерфейсам и пользовательским элементам.

Платежи #

Если ваш бот или мини-приложение продаёт цифровые товары и услуги, обязательно проводите оплату в Telegram Stars, указав XTR в качестве валюты. В соответствии с правилами сторонних магазинов Telegram не поддерживает продажу цифровых товаров и услуг за другие валюты.¶

Боты Telegram могут принимать платежи через удобный и лаконичный интерфейс, собирающий у пользователя все необходимые данные. Telegram не собирает платёжные данные, например сведения о банковской карте пользователя, а передаёт их напрямую одному из поддерживаемых сторонних платёжных провайдеров.¶

Ниже приведено краткое руководство по началу работы с платежами:¶

  • Выберите провайдера и получите подходящий токен, а также тестовый токен у провайдера «Stripe TEST MODE».
  • Реализуйте платежи с помощью соответствующих методов API.
  • Протестируйте реализацию, используя свой тестовый токен и тестовую кредитную карту.

Затем, чтобы выставить счёт и обработать заказ:¶

  • Отправьте счёт пользователю за предлагаемые товары или услуги.
  • Проверьте заказ и подтвердите оплату с помощью answerPreCheckoutQuery.
  • Подтвердите платёж, проверив наличие сервисного сообщения об успешной оплате.
  • Доставьте товары или окажите услуги.

Подробности приведены в наших полных руководствах по продаже товаров и услуг в Telegram: в них есть интерактивные контрольные списки, параметры и подробные описания методов:¶

  • Руководство по цифровым товарам и услугам
  • Руководство по физическим товарам и услугам

Telegram не обрабатывает платежи напрямую, не хранит данные о заказах и не взимает комиссию. Счета пересылаются непосредственно стороннему платёжному провайдеру.
Поэтому споры должны разрешаться между пользователем, разработчиком бота и платёжным провайдером. Подробнее об этом читайте в Политике конфиденциальности.¶

Telegram предлагает гибкую, лёгкую и бесплатную платформу для аутентификации пользователей на любом сайте и в любом приложении. С её помощью можно связать вашу платформу с Telegram и обеспечить пользователям удобную работу. Эту платформу также можно свободно использовать для реализации на сайте быстрого входа без регистрации, независимо от его связи с Telegram.¶

Шидгетс #

Виджет входа через Telegram — это простой и безопасный способ авторизовать пользователей на вашем сайте.¶

  1. Выберите бота — в идеале его имя и фото профиля должны соответствовать названию и логотипу сайта.
  2. Используйте команду /setdomain в @BotFather, чтобы связать бота с доменом вашего сайта.
  3. Настройте виджет с помощью нашего специального инструмента и разместите его на сайте.

Когда пользователи открывают ваш сайт через инлайн-кнопку, вместо виджетов входа можно использовать параметр login_url. Так вы сможете авторизовать без лишних действий их на сайте или в приложении ещё до загрузки страницы.¶

Обязательно ознакомьтесь с нашим руководством по проверке полученных данных и примером кода.¶

Игры HTML5 #

Боты могут служить самостоятельными игровыми платформами: с нашим HTML5 Gaming API вы можете разрабатывать многопользовательские или одиночные игры и дать пользователям возможность сравнивать места в рейтинге, очки и многое другое.¶

Чтобы начать, выполните следующие простые действия:¶

  • Отправьте команду /newgame в @BotFather
  • Добавьте текст описания, изображение или необязательную GIF-анимацию, чтобы показать игровой процесс
  • Отправьте игру пользователям с помощью метода sendGame или инлайн-запроса
  • Когда кто-то захочет сыграть, вы получите соответствующее значение game_short_name в CallbackQuery
  • Чтобы запустить игру, укажите URL HTML5-игры в качестве параметра url метода answerCallbackQuery

Затем, чтобы обрабатывать рекорды:¶

  • Используйте setGameScore, чтобы публиковать рекорды в чате с игрой
  • Используйте getGameHighScores, чтобы получать таблицы рекордов в игре

Вы также можете встроить кнопку «Поделиться» в игру, экспериментировать с пользовательскими инлайн-кнопками, параметрами URL и многим другим. Чтобы лучше понять возможности, ознакомьтесь с примерами:¶

  • Руководство по играм на HTML5
  • Документация Bot API по играм на HTML5

Примеры возможностей нашей игровой платформы смотрите у @GameBot и @gamee.¶

Стикеры и пользовательские эмодзи #

Стикеры и пользовательские эмодзи — отличительная функция Telegram, которой миллионы пользователей ежедневно делятся иллюстрациями. Стикеры и пользовательские эмодзи бывают самых разных видов — от обычных изображений до плавной векторной анимации и детализированных видео .WEBM.¶

Все эти форматы поддерживает наш Bot API, который позволяет ботам на ходу создавать, редактировать, удалять и публиковать новые наборы изображений. API импорта Telegram позволяет пользователям переносить наборы с других платформ и из приложений для стикеров.¶

Создание нового набора
Чтобы создать новый набор, выполните следующие действия:¶

  • Подготовьте графические материалы в соответствии с нашими техническими требованиями.
  • Создайте новый набор стикеров с помощью createStickerSet. Установите sticker_type в значение regular, чтобы создать набор стикеров, или в custom emoji, чтобы создать набор пользовательских эмодзи. Прикрепите файлы, которые хотите включить в набор, в виде массива InputSticker
  • Позднее для добавления стикеров или эмодзи можно использовать addStickerToSet.

Дополнительные возможности
Обычные стикеры и пользовательские эмодзи поддерживают ключевые слова, которые пользователи могут вводить, чтобы быстро находить соответствующие изображения. Это полезно, когда стикер не имеет очевидной связи с конкретным эмодзи. Указать их можно с помощью параметра keywords в InputSticker.¶

Пользовательские эмодзи также поддерживают адаптивные цвета — они всегда соответствуют текущему контексту (например, белые на фотографиях, цвета акцента при использовании в качестве статуса и т. д.). Чтобы включить эту возможность, используйте параметр needs_repainting в createStickerSet.¶

После создания и публикации иллюстраций не забудьте ознакомиться с нашими остальными методами для стикеров, чтобы узнать, как редактировать, удалять и даже менять порядок стикеров в наборе.¶

Обратите внимание: эти методы работают только с наборами, созданными ботом, который их вызывает.¶

Расширенные возможности форматирования #

Боты Telegram могут использовать широкий набор встроенных инструментов стилизации текста для отправки сообщений с расширенным форматированием в любом чате. Поддерживаемые форматы включают сложное вложенное выделение, код, структурированные документы, настраиваемые таблицы, математические формулы и ещё почти сто возможностей.¶

Форматирование доступно на двух уровнях — оба из них нативно отображаются во всех приложениях Telegram:¶

  • Расширенные сообщения для сложного структурированного содержимого
  • Обычные сообщения для простого форматированного текста.
Форматирование текста для ботов

Расширенные сообщения #

Расширенные сообщения предназначены для ответов со сложной структурой: отчётов, ответов ИИ в потоковом режиме, фрагментов документации, технических статей и подобного содержимого.¶

Эти сообщения поддерживают как Rich Markdown, так и Rich HTML. Rich Markdown по возможности следует GitHub Flavored Markdown и может включать поддерживаемые HTML-теги прямо в то же сообщение. Rich HTML предоставляет ботам детальное управление ещё большим числом возможностей форматирования с помощью специальных тегов.¶

Поддерживаемые стили включают:¶

  • Заголовки, абзацы, разделители, списки и списки задач.
  • Глубоко вложенное строчное форматирование, включая жирный, курсив, подчёркивание, зачёркивание, спойлер, код, нижний и верхний индекс.
  • Таблицы с выравниванием, подписями, границами, чередующимся оформлением, объединением столбцов и строк.
  • Медиаблоки для фотографий, видео и аудиофайлов с подписями и указанием авторства.
  • Блочные цитаты, выносные цитаты, сворачиваемые блоки подробностей, якоря и ссылки внутри документа
  • Сноски и текст со ссылками.
  • Полная поддержка LaTeX, включая строчные и блочные формулы.
  • Карты с пользовательскими координатами, коллажи, слайд-шоу и многое другое.

Полный синтаксис с примерами приведён здесь.¶

Обычные сообщения #

Обычные сообщения — более простая и лёгкая версия расширенных сообщений. Они поддерживают форматирование MarkdownV2 и HTML — лаконичные стили, лучше всего подходящие для короткого текста, подтверждений, простых сценариев чата и другого содержимого, не требующего сложной структуры.¶

С обычными сообщениями проще работать в базовых сценариях; они поддерживают особые взаимодействия, например частичные цитаты и цитирование сообщений в другие чаты.¶

Поддержка языков #

Боты могут адаптировать свои интерфейсы для поддержки нескольких языков — динамически обновляя поля ввода и сведения. В каждом соответствующем обновлении передаётся language_code пользователя как языковой тег IETF, что позволяет ботам соответствующим образом адаптироваться.¶

Мы рекомендуем следовать нашим рекомендациям, чтобы обеспечить наилучший пользовательский опыт.¶

  • Ваши интерфейсы, тексты и инлайн-результаты должны без вмешательства пользователя адаптироваться к language_code.
  • Подключённые WebApps получат language_code пользователя — ваша HTML-страница должна его учитывать.
  • HTML5-игры могут получать сведения о языке, если указать их в качестве параметра URL. Этот параметр можно сформировать из поля language_code объекта User, передаваемого с исходным игровым CallbackQuery.
  • Имя, описание и текст «О себе» бота можно нативно локализовать соответствующими методами.
  • Списки команд также можно задавать для отдельных языков — подробнее здесь.

Управление ботом #

Режим приватности #

Ботов часто добавляют в группы для выполнения базовых задач или помощи модераторам — например, для автоматической публикации объявлений компании или даже поздравлений с днём рождения. По умолчанию все боты, добавленные в группы, работают в режиме приватности и видят только относящиеся к ним сообщения и команды:¶

  • Команды, явно предназначенные для них (например, /command@this_bot).
  • Общие команды (например, /start), если бот последним отправил сообщение в группу.
  • Инлайн-сообщения, отправленные через бота.
  • Ответы на любые сообщения, неявно или явно предназначенные этому боту.

Все боты также получают, независимо от режима приватности:¶

  • Все сервисные сообщения.
  • Все сообщения из личных чатов.
  • Все сообщения из каналов, участниками которых они являются.

Режим приватности включён по умолчанию для всех ботов, кроме добавленных в группу администраторами (боты-администраторы всегда получают все сообщения). Его можно отключить, чтобы бот получал все сообщения как обычный пользователь (чтобы изменение вступило в силу, бота потребуется повторно добавить в группу). Мы рекомендуем делать это только в случаях, когда это абсолютно необходимо для работы бота. В большинстве случаев будет более чем достаточно использовать для сообщений бота параметр принудительного ответа.¶

Этот режим не только повышает приватность пользователей, но и делает бота эффективнее, сокращая число обрабатываемых им входящих данных. Пользователи всегда могут увидеть текущую настройку приватности бота в списке участников группы.¶

Тестирование бота #

Вы можете быстро протестировать бота без вмешательства в работу с его пользователями, просто запустив другой экземпляр вашего кода на отдельной учётной записи бота. Для этого создайте нового бота через @BotFather, получите его токен и используйте его в тестовом экземпляре кода.¶

Все дальнейшие тестирование и отладку можно проводить с новым ботом приватно, не затрагивая исходный экземпляр.¶

Если нужно совместно использовать ссылки на файлы между ботами, учтите, что поле file_id привязано к идентификатору одного бота, поэтому тестовый экземпляр не может использовать общую базу данных file_id для быстрой отправки медиа — файлы нужно загружать повторно по отдельности.¶

Выделенная тестовая среда #

Telegram также предлагает выделенную тестовую среду, подходящую для более сложного тестирования. Для ботов и пользователей в этой среде обычно действуют более гибкие ограничения — например:¶

  • При работе в тестовой среде можно использовать HTTP-ссылки без TLS для тестирования Web Apps или Web Login.

Лимиты флуда в тестовой среде не повышены и иногда могут быть строже. Чтобы свести влияние этого к минимуму, следует убедиться, что бот обрабатывает ошибки с политиками повторных попыток и не зависит от жёстко заданных значений лимитов.¶

Создание бота в тестовой среде #

Тестовая среда полностью отделена от основной, поэтому потребуется создать новую учётную запись пользователя и нового бота через @BotFather.¶

Для создания учётной записи и входа используйте один из следующих способов:¶

  • iOS: нажмите 10 раз значок «Настройки» > «Учётные записи» > «Войти в другую учётную запись» > «Тест».
  • Telegram Desktop: откройте ☰ «Настройки» > Shift + Alt + щелчок правой кнопкой мыши по «Добавить аккаунт» и выберите «Тестовый сервер».
  • macOS: нажмите значок «Настройки» 10 раз, чтобы открыть меню отладки, ⌘ + щелчок по «Добавить аккаунт», затем войдите по номеру телефона.

После входа просто создайте нового бота, следуя стандартной процедуре, и отправляйте запросы к Test Bot API в таком формате:¶

https://api.telegram.org/bot<token>/test/METHOD_NAME

При работе в тестовой среде можно использовать HTTP-ссылки без TLS в поле url как LoginUrl, так и WebAppInfo.¶

Оповещения о состоянии #

Миллионы выбирают Telegram за его скорость. Чтобы пользователи получали максимум преимуществ, бот также должен быстро реагировать. Чтобы помочь разработчикам поддерживать ботов в форме, @BotFather отправит оповещения о состоянии, если обнаружит неполадку.¶

Мы проверяем число ответов и коэффициент преобразования запрос/ответ у популярных ботов (около 300 запросов в минуту; это значение может измениться в будущем). Если бот возвращает аномально мало ответов, вы получите уведомление от @BotFather.¶

Реагирование на оповещения #

По умолчанию вы получите только одно оповещение на бота в час.¶

В каждом оповещении есть следующие кнопки:¶

  • Исправлено — используйте, если нашли и исправили проблему с ботом. При нажатии кнопки исправления мы возобновим обычную отправку оповещений, чтобы через 5–10 минут, а не через час, вы могли увидеть, сработало ли исправление.
  • Поддержка — используйте, чтобы открыть чат с @BotSupport, если не видите проблем с ботом или считаете, что проблема на нашей стороне.
  • Отключить на 8 ч/1 нед — используйте, если сейчас не можете исправить бота. Это отключит все оповещения для данного бота на указанный срок. Мы не рекомендуем использовать эту возможность: пользователи могут перейти к более стабильному боту. Включить оповещения обратно можно в настройках бота через @BotFather.
Отслеживаемые проблемы #

Сейчас мы уведомляем о следующих проблемах:¶

  • Слишком мало отправленных личных сообщений. Значение: {value} — ваш бот отправляет гораздо меньше сообщений, чем в предыдущие недели. Это полезно для ботов-рассылок, которые отправляют сообщения без запросов пользователей. Чем больше значение, тем существеннее разница.¶

  • Слишком мало ответов на входящие личные сообщения. Коэффициент преобразования: {value} — бот отвечает не на все отправляемые ему сообщения (коэффициент преобразования запрос/ответ для бота был слишком низким как минимум в двух из трёх последних 5-минутных периодов).¶

Чтобы обеспечить хороший пользовательский опыт, отвечайте на все сообщения, отправленные боту. Отвечайте на обновления сообщений, вызывая методы send… (например, sendMessage).¶

  • Слишком мало ответов на инлайн-запросы. Коэффициент преобразования: {value} — бот отвечает не на все отправляемые ему инлайн-запросы; расчёт выполняется так же, как выше. Отвечайте на обновления inline_query, вызывая answerInlineQuery.¶

  • Слишком мало ответов на callback-запросы. Коэффициент преобразования: {value}¶

  • Слишком мало ответов на callback-запросы игр. Коэффициент преобразования: {value} — бот отвечает не на все отправляемые ему callback-запросы (с играми или без них); расчёт выполняется так же, как выше. Отвечайте на обновления callback_query, вызывая answerCallbackQuery.¶

Бот BotFather #

Ниже приведено подробное руководство по использованию @BotFather — инструмента Telegram для создания и управления ботами.¶

Создание нового бота #

Используйте команду /newbot, чтобы создать нового бота. @BotFather запросит имя и имя пользователя, затем создаст токен аутентификации для нового бота.¶

  • Имя бота отображается в сведениях о контакте и других местах.¶

  • Имя пользователя — короткое имя, используемое в поиске, упоминаниях и ссылках t.me. Имена пользователя имеют длину 5–32 символа и не чувствительны к регистру, но могут содержать только латинские буквы, цифры и подчёркивания. Имя пользователя бота должно оканчиваться на «bot», например «tetris_bot» или «TetrisBot».¶

  • Токен — строка наподобие 110201543:AAHdqTcvCH1vGWJxfSeofSAs0K5PALDsaw, необходимая для авторизации бота и отправки запросов к Bot API. Храните токен в безопасности: любой может использовать его для управления ботом.¶

В отличие от имени бота, имя пользователя нельзя изменить позднее — выбирайте его внимательно.
При отправке запроса на api.telegram.org не забудьте добавить к токену слово «bot» в качестве префикса.¶

Текст «О себе», описание и медиа профиля #

Когда новые пользователи открывают бота, они увидят полезное описание в блоке с заголовком «Что умеет этот бот?».¶

Правильная настройка этого поля в @BotFather позволяет всем сразу понять, что умеет бот: описание должно быть кратким, точным и по теме.¶

Также к этому полю можно добавить фото или видео с помощью Edit Description Picture в @BotFather.¶

Кроме того, как и обычные пользователи, боты имеют краткое описание, доступное в профиле. Если это поле не было задано при первом создании бота, его можно установить в любое время командой /setabouttext в @BotFather. Пользователи могут взаимодействовать со многими ботами и после запуска не имеют доступа к их описанию — краткое напоминание о назначении бота может быть очень полезно.¶

Обратите внимание: и описание, и текст «О себе» можно нативно локализовать — каждый пользователь автоматически увидит верный перевод на своём языке.¶

У ботов также может быть фото профиля — выберите что-то уникальное и оригинальное, чтобы пользователи могли сразу найти его в списке чатов.¶

Начиная с 21 апреля 2023 года (Telegram 9.6) бота можно редактировать прямо со страницы его профиля, в том числе установить пользовательское видео профиля.¶

Создание токена аутентификации #

Если существующий токен скомпрометирован или потерян, используйте команду /token, чтобы создать новый.¶

Передача прав владения #

Права владения ботом можно передать другому пользователю.
Для этого отправьте /mybots, выберите бота, затем передать права владения.
Передать бота можно только пользователям, которые хотя бы раз взаимодействовали с ним.¶

Передача прав владения даёт другому пользователю полный контроль над ботом: он сможет получать доступ к сообщениям бота и даже удалить его. Передача необратима, поэтому хорошо всё обдумайте.¶

  • /mygames — делает то же самое для ваших игр.

Можно использовать доступные команды:¶

  • /setname — изменить имя бота.
  • /setdescription — изменить описание бота (короткий текст до 512 символов). Пользователи увидят этот текст в начале диалога с ботом под заголовком «Что умеет этот бот?».
  • /setabouttext — изменить сведения о боте — более короткий текст до 120 символов. Пользователи увидят его на странице профиля бота. Когда они поделятся ботом с кем-то, этот текст будет отправлен вместе со ссылкой.
  • /setuserpic — изменить фото профиля бота.
  • /setcommands — изменить список команд, поддерживаемых ботом. Пользователи увидят эти команды как подсказки, когда введут / в чате с ботом. Подробнее см. команды.
  • /setdomain — привязать к боту домен веб-сайта. См. раздел виджета входа.
  • /deletebot — удалить бота и освободить его имя пользователя. Отменить нельзя.

Или используйте команду /mybots, выберите бота и редактируйте его в современном инлайн-интерфейсе.¶

Начиная с 21 апреля 2023 года (Telegram 9.6) общедоступные сведения о боте можно редактировать прямо со страницы его профиля, в том числе установить пользовательское видео профиля.¶

Редактирование настроек #

  • /setinline — включить или выключить для бота инлайн-режим.
  • /setinlinegeo — запросить данные геолокации для предоставления инлайн-результатов с учётом местоположения.
  • /setjoingroups — включить или выключить возможность добавлять бота в группы. Все боты должны уметь обрабатывать личные сообщения, но если бот не предназначен для работы в группах, эту возможность можно отключить.
  • /setinlinefeedback — включить или выключить отправку API обновлений о выбранных пользователями результатах. Подробное объяснение приведено здесь.
  • /setprivacy — указать, какие сообщения бот будет получать при добавлении в группу. Подробнее см. режим приватности.

Управление играми #

  • /newgame — создать новую игру.
  • /listgames — просмотреть список игр.
  • /editgame — изменить игру.
  • /deletegame — удалить существующую игру.

Обратите внимание: применение изменений может занять несколько минут.¶
