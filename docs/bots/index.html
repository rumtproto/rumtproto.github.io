Боты: введение для разработчиков #

Боты — это небольшие приложения, которые работают непосредственно в приложении Telegram. Пользователи взаимодействуют с ботами через гибкие интерфейсы, способные поддерживать любые задачи и сервисы. Подробнее см.:¶

  • Detailed Guide to Bot Features
  • Full API Reference for Developers
  • Basic Tutorial: From @BotFather to 'Hello World'

На платформе Telegram для ботов размещено более 10 миллионов ботов; она бесплатна и для пользователей, и для разработчиков.¶

Заменять целые веб-сайты #

В Telegram-ботах можно размещать Mini Apps, созданные на JavaScript. Благодаря этому доступны бесконечно гибкие интерфейсы для всего — от интернет-магазинов до аркадных игр. В отличие от веб-сайтов, боты изначально поддерживают бесшовную авторизацию и уведомления через Telegram.¶

Попробуйте @DurgerKingBot или ознакомьтесь со специальным руководством по Mini Apps, чтобы создать собственное приложение.¶

Нативно интегрировать чат-ботов с ИИ #

Боты нативно поддерживают ветвящиеся беседы, позволяющие параллельно работать с несколькими разными темами. Это особенно полезно при создании чат-ботов с ИИ и даёт пользователям удобный доступ к информации из предыдущих чатов.¶

Не дожидаясь полного ответа, чат-боты также могут транслировать ответы в реальном времени по мере их создания.¶

Можно легко включить темы в личных чатах, активировав Threaded Mode через @BotFather.¶

За эту функцию взимается дополнительная плата в Telegram Stars, как описано в разделе 6.2.6 наших Условий обслуживания для разработчиков ботов.¶

Управлять бизнесом #

Пользователи Telegram Business могут подключать Telegram-ботов для обработки сообщений и ответов на них от своего имени через личный аккаунт. Это позволяет компаниям бесшовно интегрировать любые существующие инструменты и рабочие процессы либо добавлять новых ИИ-помощников для повышения производительности.¶

По мере расширения набора бесплатных инструментов, доступных ботам благодаря этой интеграции, мы призываем всех разработчиков внедрять инновации и создавать полезные приложения и сервисы для бизнеса в Telegram.¶

Кроме того, физические товары можно легко приобретать через сторонних поставщиков, поддерживающих интеграцию с Mini Apps.¶

Как работают боты? #

Подробное описание возможностей ботов см. в этом руководстве¶

Telegram-боты — это специальные аккаунты, для создания которых не нужен номер телефона. Боты подключены к серверу владельца, который обрабатывает вводимые пользователями данные и запросы.¶

Промежуточный сервер Telegram выполняет всё шифрование и взаимодействует с Telegram API. Разработчики работают с этим сервером через простой HTTPS-интерфейс с упрощённой версией Telegram API, известной как Bot API.¶

Чем боты отличаются от пользователей? #

Боты способны обрабатывать вводимые данные и запросы способами, недоступными аккаунтам пользователей, но между ботом и обычным пользователем есть несколько различий.¶

  • У ботов нет статуса «был(а) недавно» или онлайн-статуса — вместо этого в чате отображается метка «bot».
  • У ботов ограниченное облачное хранилище — старые сообщения могут быть удалены сервером вскоре после обработки.
  • Боты не могут первыми начинать беседы с пользователями. Пользователь должен либо добавить их в группу, либо сначала отправить им сообщение. Люди могут искать имя пользователя вашего бота или начать чат по его уникальной ссылке t.me/bot_username.
  • По умолчанию боты, добавленные в группы, видят только релевантные сообщения в чате (см. режим конфиденциальности).
  • Боты никогда не едят, не спят и не жалуются (если только они не запрограммированы иначе).

Ссылки на ботов #

Имена пользователей ботов обычно требуют суффикса «bot», но у некоторых ботов его нет — например, у @stickers, @gif, @wiki или @bing.¶

Любой может назначить коллекционные имена пользователей ботам, в том числе без суффикса «bot».¶

Как создать бота? #

Создавать Telegram-ботов очень просто, но потребуются хотя бы базовые навыки программирования.¶

Создание бота упрощает Bot API Telegram, предоставляющий инструменты и основу для интеграции вашего кода. Чтобы начать, напишите @BotFather в Telegram, зарегистрируйте бота и получите его токен авторизации.¶

Ваш токен бота — его уникальный идентификатор. Храните его в безопасном месте и сообщайте только людям, которым необходим прямой доступ к боту. Каждый, у кого есть ваш токен, получает полный контроль над ботом.¶
