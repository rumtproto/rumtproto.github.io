Журнал изменений Bot API #

Bot API — HTTP-интерфейс для разработчиков, желающих создавать ботов для Telegram.
Чтобы узнать, как создать и настроить бота, ознакомьтесь с нашим Введением в ботов »¶

На этой странице приведены все изменения Bot API.¶

Последние изменения #

Подпишитесь на @BotNews, чтобы первыми узнавать о последних обновлениях, и присоединяйтесь к обсуждению в @BotTalk¶

2026 #

14 июля 2026 года #

Версия Bot API 10.2¶

Расширенные сообщения¶

  • Добавлен класс InputRichMessageMedia и поле media в класс InputRichMessage, позволяющий ботам explicitly specify media используемые в markdown or html форматирования when sending расширенное сообщение.
  • Добавлен класс InputMediaVoiceNote, представляющий отправляемое голосовое сообщение.
  • Добавлен класс InputRichBlockListItem, который представляет item в отправляемого списка.
  • Добавлены классы InputRichBlockParagraph, InputRichBlockSectionHeading, InputRichBlockPreformatted, InputRichBlockFooter, InputRichBlockDivider, InputRichBlockMathematicalExpression, InputRichBlockAnchor, InputRichBlockList, InputRichBlockBlockQuotation, InputRichBlockPullQuotation, InputRichBlockCollage, InputRichBlockSlideshow, InputRichBlockTable, InputRichBlockDetails, InputRichBlockMap, InputRichBlockAnimation, InputRichBlockAudio, InputRichBlockPhoto, InputRichBlockVideo, InputRichBlockVoiceNote и InputRichBlockThinking, которые представляют различные типы блоков доступные для format исходящего расширенное сообщение.
  • Добавлено поле blocks в класс InputRichMessage, позволяющий ботам specify расширенное сообщение форматирования via блочные сущности.

Эфемерные сообщения¶

  • Добавлена поддержка Ephemeral Messages, позволяющий ботам отправлять групповые сообщения и получать команды that являются visible only для определённому пользователю и bot.
  • Добавлено поле is_ephemeral в класс BotCommand.
  • Добавлено поле receiver_user в класс Message.
  • В класс Message добавлено поле ephemeral_message_id.
  • Добавлены параметры receiver_user_id и callback_query_id для methods sendMessage, sendAnimation, sendAudio, sendDocument, sendLivePhoto, sendPhoto, sendSticker, sendVideo, sendVideoNote, sendVoice, sendContact, sendLocation, sendVenue.
  • В класс ReplyParameters добавлено поле ephemeral_message_id, позволяющее ботам отвечать на эфемерные сообщения.
  • Поле message_id в классе ReplyParameters помечено как необязательное, если присутствует поле ephemeral_message_id.
  • Добавлены методы editEphemeralMessageText, editEphemeralMessageMedia, editEphemeralMessageCaption, и editEphemeralMessageReplyMarkup позволяющий ботам edit ephemeral сообщениеs.
  • Добавлен метод deleteEphemeralMessage позволяющий ботам delete ephemeral сообщениеs.

Сообщества¶

  • Добавлена начальная поддержка Communities — нескольких супергрупп, каналов и ботов, объединённых общей темой или аудиторией.
  • Добавлен класс Community который представляет сообщество.
  • Добавлены уведомление о добавлении чата сообщества и поле community_chat_added в класс Message.
  • Добавлен класс CommunityChatRemoved и поле community_chat_removed в класс Message.
  • Добавлено поле community в класс ChatFullInfo.

Общее¶

  • Добавлены обновления о changes для пользовательской платёжной подписки, represented by class BotSubscriptionUpdated и поле subscription в классе Update.
  • Безопасность Mini Apps усилена: использование методов Mini App запрещено для источников, отличающихся от исходного домена Mini App. Защита будет автоматически включена для всех Mini Apps 20 июля 2026 года. От неё можно отказаться через Mini App @BotFather. В этом случае вы признаёте, что бот несёт ответственность за отсутствие в Mini App ссылок на недоверенные сайты.

  • Добавлен класс RichText, который представляет с расширенным форматированием text.
  • Добавлен класс RichBlockCaption, который представляет подпись к с расширенным форматированием text.
  • Добавлен класс RichBlockTableCell, который представляет ячейку в таблице.
  • Добавлен класс RichBlockListItem, который представляет элемент списка.
  • Добавлены классы RichBlockParagraph, RichBlockSectionHeading, RichBlockPreformatted, RichBlockFooter, RichBlockDivider, RichBlockMathematicalExpression, RichBlockAnchor, RichBlockList, RichBlockBlockQuotation, RichBlockPullQuotation, RichBlockCollage, RichBlockSlideshow, RichBlockTable, RichBlockDetails, RichBlockMap, RichBlockAnimation, RichBlockAudio, RichBlockPhoto, RichBlockVideo, RichBlockVoiceNote и RichBlockThinking, которые представляют различные типы блоков в с расширенным форматированием сообщение.

  • Добавлен класс RichMessage, который представляет с расширенным форматированием сообщение.
  • В класс Message добавлено поле rich_message.

  • Добавлен класс InputRichMessageContent и разрешено использовать его как InputMessageContent в результатах инлайн-, гостевых запросов и запросов Web App.
  • Добавлен метод sendRichMessage, позволяющий ботам отправлять расширенное сообщениеs.
  • Добавлен метод sendRichMessageDraft, позволяющий ботам stream partial расширенное сообщениеs.
  • В метод editMessageText добавлен параметр rich_message, позволяющий ботам редактировать форматированные сообщения.

Запросы на вступление¶

  • Добавлено поле supports_join_request_queries в класс User.
  • Добавлено поле guard_bot в класс ChatFullInfo.
  • Добавлено поле query_id в класс ChatJoinRequest.
  • Добавлен метод answerChatJoinRequestQuery.
  • Добавлен метод sendChatJoinRequestWebApp.

Опросы¶

  • Добавлен класс Link и поле link в класс PollMedia.
  • Добавлен класс InputMediaLink и разрешено использовать его как InputPollOptionMedia.

Версия Bot API 10.0¶

Гостевой режим¶

  • Добавлена поддержка гостевого режима: боты могут получать некоторые сообщения и отвечать в чатах, участниками которых они не являются.
  • Добавлено поле supports_guest_queries в класс User.
  • Добавлены поля guest_bot_caller_user and guest_bot_caller_chat в класс Message.
  • Добавлено поле guest_query_id в класс Message.
  • В класс Update добавлено поле guest_message.
  • Добавлен класс SentGuestMessage и метод answerGuestQuery.

Управление чатами¶

  • В классы ChatMemberRestricted и ChatPermissions добавлено поле can_react_to_messages.
  • Добавлен параметр return_bots в метод getChatAdministrators.
  • Добавлен метод deleteAllMessageReactions.
  • Добавлен метод deleteMessageReaction.
  • Добавлена возможность видеть определённые сообщения, отправленные другими ботами в группах.

Опросы¶

  • Добавлены классы InputMediaSticker, InputMediaLocation, и InputMediaVenue.
  • Добавлен класс PollMedia, представляющий медиа в опросе.
  • Добавлено поле media в класс Poll, позволяющий ботам видеть медиа в опросах.
  • Добавлено поле explanation_media в класс Poll, позволяющий ботам видеть медиа в пояснениях к викторинам.
  • Добавлено поле media в класс PollOption, позволяющий ботам видеть медиа в вариантах опроса.
  • Добавлен класс InputPollMedia и параметры media и explanation_media в метод sendPoll, позволяющий ботам добавлять медиа в опросы.
  • Добавлен класс InputPollOptionMedia и поле media в класс InputPollOption, позволяющий ботам добавлять медиа в варианты опроса.
  • Добавлено поле members_only в класс Poll.
  • Добавлен параметр members_only в метод sendPoll.
  • Добавлено поле country_codes в класс Poll.
  • Добавлен параметр country_codes в метод sendPoll.
  • Минимальное число вариантов опроса уменьшено с 2 до 1.

Живые фотографии¶

  • Добавлен класс LivePhoto, который представляет фотографию с коротким видео.
  • Добавлен класс InputMediaLivePhoto.
  • Добавлено поле live_photo в классы Message и ExternalReplyInfo.
  • Добавлен метод sendLivePhoto, позволяющий ботам отправлять живые фотографии.
  • Добавлен класс PaidMediaLivePhoto, описывающий платный медиафайл с живой фотографией.
  • Добавлен класс InputPaidMediaLivePhoto, позволяющий ботам отправлять живые фотографии as paid media.
  • Разрешено использовать живые фотографии в sendMediaGroup и editMessageMedia,

Общее¶

  • Business Bots разрешено управлять учётными записями пользователей без подписки Telegram Premium.
  • Добавлена возможность отправлять сообщения другим ботам по имени пользователя, если оба бота включили связь между ботами.
  • Добавлена возможность отвечать другим ботам от имени бизнес-бота, если бизнес-бот включил связь между ботами.
  • Ботам разрешено pass empty text в методе sendMessageDraft.
  • Добавлен класс BotAccessSettings и метод getManagedBotAccessSettings.
  • Добавлен метод setManagedBotAccessSettings.
  • Добавлен метод getUserPersonalChatMessages.

Для этого бот должен быть администратором канала (именно добавление ботов в администраторы пока не поддерживается клиентами Telegram, но появится в ближайшее время).

18 сентября 2015 года #

  • Теперь боты могут скачивать файлы и медиа, отправленные пользователями.
  • Добавлены getFile и File.

7 сентября 2015 года #

  • Теперь можно передавать параметры с помощью application/json (обратите внимание, что это не работает для загрузки файлов: используйте multipart/form-data для загрузки файлов).
  • Добавлена базовая поддержка markdown. В sendMessage добавлено новое поле parse_mode. Пока что сообщения с markdown будут корректно отображаться только в Telegram для Android. Другие официальные приложения скоро их поддержат.

29 августа 2015 года #

  • Добавлена поддержка самоподписанных сертификатов: загрузите свой сертификат, используя параметр certificate в методе setWebhook.
  • Теперь можно выполнять новые запросы при ответе на обновления webhook.

15 августа 2015 года #

  • Добавлены новый тип Voice и новый метод sendVoice для отправки голосовых сообщений.
  • Прежние Audio и sendAudio теперь следует использовать для отправки музыкальных файлов. Клиенты Telegram будут отображать такие файлы во встроенном музыкальном проигрывателе. Если вы использовали sendAudio, чтобы бот отправлял голосовые сообщения, используйте вместо него sendVoice.
  • В объект Audio и метод sendAudio добавлены необязательные поля performer и title.
  • В объект Message добавлено необязательное поле voice.

Июль 2015 года #

  • Поле thumb теперь необязательно для объектов Video, Sticker и Document
  • API теперь поддерживает подписи как к видео, так и к фотографиям. Поле caption удалено из объекта Video и вместо этого добавлено в объект Message.
  • В метод sendVideo добавлены необязательные поля caption и duration.
  • Исправлена опечатка: user_id в объекте Contact теперь правильно обозначено как Integer, а не String
