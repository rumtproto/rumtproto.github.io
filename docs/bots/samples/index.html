Примеры библиотек для Bot API #

Доступно полное руководство, охватывающее всё — от настройки окружения до развёртывания готового бота: здесь.¶

На этой странице перечислены некоторые библиотеки и фреймворки, разработанные сообществом Telegram. Обо всех найденных ошибках следует сообщать соответствующим разработчикам, поскольку Telegram не поддерживает эти проекты.¶

Напишите нам в @BotSupport, если хотите, чтобы ваша библиотека появилась на этой странице.¶
