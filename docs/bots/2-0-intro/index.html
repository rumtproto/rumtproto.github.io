Представляем Bot API 2.0 #

Привет! Этот текст предполагает, что вы знакомы с платформой Telegram для ботов.
Если это не так, пожалуйста, ознакомьтесь с нашим введением для ботов.¶

Сегодня мы представляем самое крупное изменение платформы Telegram для ботов с июня 2015 года. Эти новые инструменты помогут создавать плавные и интуитивно понятные интерфейсы для ботов. Боты также становятся намного функциональнее. Теперь они могут отправлять любые типы контента, поддерживаемые в Telegram, предоставлять сервисы с учётом местоположения и глубоко интегрироваться с другими сервисами на основе номеров телефонов пользователей.¶

Более краткий список изменений приведён в руководстве по Bot API.¶

Новые инлайн-клавиатуры #

Начнём с нового типа клавиатуры, встроенной прямо в сообщение, которому она принадлежит. Инлайн-клавиатуры доступны для сообщений, отправляемых и в режиме чата, и в инлайн-режиме.¶

Кнопки обратного вызова в @music Больше кнопок обратного вызова в @music¶

В отличие от пользовательских клавиатур для ответов, нажатие кнопок на инлайн-клавиатурах не отправляет сообщения в чат. Вместо этого инлайн-клавиатуры поддерживают кнопки, работающие в фоновом режиме: callback-кнопки, URL-кнопки и кнопки перехода в инлайн-режим.¶

Руководство: инлайн-клавиатуры »¶

Callback-кнопки #

Когда пользователь нажимает callback-кнопку, в чат не отправляются сообщения. Вместо этого бот просто получает соответствующий запрос. Получив запрос, бот может показать результат в уведомлении в верхней части экрана чата или в предупреждении.¶

Пример бота
@music — этот демонстрационный музыкальный бот использует инлайн callback-кнопки для переключения страниц и загрузки случайных результатов.¶

Читайте далее о обновлении сообщений, чтобы узнать, как callback-кнопки могут стать ещё удобнее.¶

URL-кнопки #

У кнопок этого типа есть маленький значок стрелки, помогающий пользователю понять, что нажатие URL-кнопки откроет внешнюю ссылку. Разумеется, перед открытием ссылки в браузере будет показано окно подтверждения.¶

Кнопки перехода в инлайн-режим #

Нажатие кнопки перехода в инлайн-режим предлагает пользователю выбрать чат, открывает его и вставляет имя пользователя бота в поле ввода. Можно также передать запрос, который будет вставлен вместе с именем пользователя, — так пользователи сразу получат инлайн-результаты, которыми смогут поделиться.¶

Пример бота
@sticker — этот бот для поиска стикеров предлагает кнопку «переход в инлайн-режим», чтобы научить пользователей работать с ним в инлайн-режиме.¶

Обновление сообщений #

Поскольку инлайн-клавиатуры не отправляют в чат дополнительные сообщения, ботам предоставлен способ изменять уже существующие сообщения, чтобы не отправлять новое при каждом обновлении. Это помогает уменьшить беспорядок и создавать более плавные интерфейсы.¶

Пример бота
@music — посмотрите, как музыкальный бот обновляет сообщения с результатами поиска при нажатии навигационных кнопок.¶

Руководство: изменение сообщений »¶

Местоположение и номера #

Некоторым ботам для правильной работы нужны дополнительные данные от пользователя. Например, знание местоположения пользователя помогает предоставлять более релевантные географические результаты. Номер телефона пользователя может быть очень полезен для интеграции с другими сервисами, например банками.¶

Мы добавили простой способ для ботов запрашивать у пользователя местоположение и номер телефона с помощью специальных кнопок. Обратите внимание: кнопки запроса номера телефона и местоположения работают только в личных чатах.¶

При нажатии этих кнопок клиенты Telegram показывают окно подтверждения, сообщающее пользователю, что сейчас произойдёт.¶

Руководство: кнопки номера и геопозиции »¶

Инлайн-боты также могут запрашивать у пользователей данные о местоположении. Чтобы включить эту возможность, используйте команду /setinlinegeo в @BotFather. Бот будет запрашивать у пользователя разрешение на доступ к местоположению при каждом инлайн-запросе.¶

Пример бота
@foursquare — этот бот запросит разрешение на доступ к местоположению пользователя, а затем предоставит результаты с учётом географической привязки.¶

Инлайн-боты 2.0 #

Кстати, инлайн-боты также получают сегодня крупное обновление.¶

Новые типы контента #

Инлайн-боты теперь поддерживают все доступные в Telegram типы контента (всего 19) и способны отправлять стикеры, видео, музыку, местоположения, документы и многое другое.¶

Примеры ботов
@sticker — этот бот для стикеров принимает один или несколько эмодзи и ищет подходящие стикеры.
@music — музыкальный бот позволяет пользователям отправлять mp3-треки из базы классической музыки, находящейся в общественном достоянии.¶

Руководство: типы инлайн-содержимого »¶

Переключение между инлайн-режимом и личным чатом #

Некоторым инлайн-ботам полезна первоначальная настройка, например подключение к аккаунту внешнего сервиса (например, YouTube). Мы добавили простой способ переключаться между личным чатом с ботом и любым чатом, в котором пользователь хочет поделиться инлайн-результатами.¶

Теперь над инлайн-результатами (или вместо них) можно отображать специальную кнопку «Перейти в ЛС». Эта кнопка откроет личный чат с ботом и передаст выбранный вами параметр, чтобы запросить у пользователя необходимые действия по настройке. После этого можно с помощью инлайн-клавиатуры с кнопкой switch_inline_query вернуть пользователя в исходный чат.¶

Примеры ботов
@youtube — показывает кнопку «Войти в YouTube», затем предлагает персонализированные результаты.¶

Руководство: переход в личный чат¶

Улучшенный интерфейс инлайн-режима #

Поскольку отправка контента через инлайн-ботов отличается от отправки обычных сообщений, мы немного изменили интерфейс. Вряд ли есть более наглядный способ объяснить, что нажимать «Отправить» не нужно:¶

Одно нажатие значка крестика очистит запрос, а два нажатия вернут пользователю кнопку «Отправить».¶
